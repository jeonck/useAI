⏱ **소요 시간:** 12분

✅ **이 페이지를 끝내면 할 수 있는 것**
- 재료비 목록을 넣으면 메뉴별 1인분 원가·마진율 표가 나옵니다.
- 가격 인상 시나리오 3개와 손익분기 매출을 계산기 없이 뽑습니다.
- 세트 메뉴 구성 제안을 받고, 계산 결과를 검산하는 습관을 갖습니다.

{{< callout type="error" >}}
**AI는 계산 실수를 합니다.** 곱셈·나눗셈에서 틀리고, 단위를 헷갈립니다. 이 페이지의 모든 프롬프트에 "계산 과정을 보여줘"가 들어 있는 이유입니다. 나온 숫자 중 최소 1개는 사장님이 계산기로 직접 검산하세요. 가격표에 반영하기 전에는 전부 검산하세요.
{{< /callout >}}

## 무엇부터: 재료비 준비 (2분)

메모앱에 이렇게 적어 두세요. 정확하지 않아도 됩니다. 영수증 기준 대략적인 값이면 충분합니다.

```text
재료명 / 구매 단위 / 구매 가격 / 1인분 사용량
```

예시 (커피한잔, 아메리카노):

```text
원두 / 1kg / 28,000원 / 18g
물 / - / 0원 / 250ml
테이크아웃 컵+뚜껑 / 100개 / 12,000원 / 1개
빨대 / 500개 / 5,000원 / 1개
```

여기 적힌 가격은 형식을 보여주기 위한 가상의 숫자입니다. 사장님 영수증 숫자로 바꾸세요.

## 그다음: 1인분 원가·마진율 표 (3분)

**복붙 프롬프트**

```text
[컨텍스트 카드 붙여넣기]

아래는 우리 가게 [메뉴명]의 재료 목록이야.
재료명 / 구매 단위 / 구매 가격 / 1인분 사용량

[재료 목록 붙여넣기]

현재 판매가는 [판매가]원이야.

해줄 것:
1. 재료별 1인분 원가를 계산해서 표로 만들어줘 (재료명, 1인분 원가, 계산식 칸 포함)
2. 1인분 총 재료 원가와 재료 원가율(원가 ÷ 판매가)을 계산해줘
3. 모든 계산 과정을 한 줄씩 보여줘. 반올림은 마지막에 한 번만 해줘
4. 이상하게 크거나 작은 숫자가 있으면 "확인 필요"라고 표시해줘
```

**완성 예시** (동네 카페 "커피한잔")

```text
[컨텍스트 카드 붙여넣기]

아래는 우리 가게 아메리카노의 재료 목록이야.
재료명 / 구매 단위 / 구매 가격 / 1인분 사용량

원두 / 1kg / 28,000원 / 18g
테이크아웃 컵+뚜껑 / 100개 / 12,000원 / 1개
빨대 / 500개 / 5,000원 / 1개

현재 판매가는 4,000원이야.

해줄 것:
1. 재료별 1인분 원가를 계산해서 표로 만들어줘 (재료명, 1인분 원가, 계산식 칸 포함)
2. 1인분 총 재료 원가와 재료 원가율(원가 ÷ 판매가)을 계산해줘
3. 모든 계산 과정을 한 줄씩 보여줘. 반올림은 마지막에 한 번만 해줘
4. 이상하게 크거나 작은 숫자가 있으면 "확인 필요"라고 표시해줘
```

**예상 결과**

재료별 1인분 원가 표, 합계, 원가율이 나옵니다. "계산식" 칸에 `28,000 ÷ 1,000 × 18` 같은 식이 보입니다.

**다듬는 법**

계산식 칸의 식 하나를 골라 계산기로 두드려 보세요. 맞으면 나머지도 대체로 맞습니다. 틀리면 이렇게 쓰세요.

```text
원두 원가 계산이 틀렸어. 1kg = 1,000g이야. 다시 계산하고, 나머지 항목도 단위 환산을 전부 다시 확인해줘.
```

메뉴가 여러 개면 한 번에 하나씩 하세요. 한꺼번에 넣으면 실수가 늘어납니다.

{{< callout type="info" >}}
여기서 계산한 건 **재료 원가**만입니다. 인건비, 임대료, 전기세는 아직 안 들어갔습니다. 그건 아래 손익분기 계산에서 다룹니다.
{{< /callout >}}

## 그다음: 가격 인상 시나리오 3개 (2분)

**복붙 프롬프트**

```text
위에서 계산한 [메뉴명] 원가를 기준으로, 가격 인상 시나리오 3개를 표로 만들어줘.
- 시나리오 A: 소폭 인상 [금액 또는 %]
- 시나리오 B: 중간 인상 [금액 또는 %]
- 시나리오 C: 큰 폭 인상 [금액 또는 %]
표 항목: 새 판매가, 1잔당 이익, 원가율, 하루 [예상 판매 수량]잔 기준 하루 이익
각 시나리오마다 손님 입장에서 어떻게 느낄지 한 줄, 사장 입장에서 위험 요소 한 줄.
계산 과정을 전부 보여줘.
```

**완성 예시** (동네 카페 "커피한잔")

```text
위에서 계산한 아메리카노 원가를 기준으로, 가격 인상 시나리오 3개를 표로 만들어줘.
- 시나리오 A: 소폭 인상 200원
- 시나리오 B: 중간 인상 500원
- 시나리오 C: 큰 폭 인상 1,000원
표 항목: 새 판매가, 1잔당 이익, 원가율, 하루 80잔 기준 하루 이익
각 시나리오마다 손님 입장에서 어떻게 느낄지 한 줄, 사장 입장에서 위험 요소 한 줄.
계산 과정을 전부 보여줘.
```

**예상 결과**

3행짜리 비교표와 각 시나리오의 장단점이 나옵니다. "손님이 떠날 수 있다" 같은 판단은 AI의 추측입니다. 참고만 하세요.

**다듬는 법**

```text
시나리오 B로 정했어. 손님에게 가격 인상을 알리는 안내문을 3줄로 써줘. 사과보다는 이유(재료비 상승)를 짧게.
```

## 그다음: 손익분기 매출 (3분)

"한 달에 얼마를 팔아야 본전인가"를 계산합니다. 월 고정비를 먼저 적어 두세요.

**복붙 프롬프트**

```text
우리 가게 월 고정비야:
- 임대료: [금액]원
- 인건비: [금액]원
- 공과금(전기·수도·가스·통신): [금액]원
- 기타 고정비(보험, 구독, 대출이자 등): [금액]원

대표 메뉴 [메뉴명]의 판매가는 [판매가]원, 1인분 재료 원가는 [원가]원이야.

해줄 것:
1. 월 고정비 합계
2. 1인분당 이익(판매가 - 재료 원가)
3. 손익분기 판매 수량 = 월 고정비 ÷ 1인분당 이익
4. 손익분기 매출 = 손익분기 수량 × 판매가
5. 한 달 [영업일수]일 기준 하루에 몇 인분을 팔아야 하는지
계산 과정을 한 줄씩 보여줘. 결과는 표로 정리해줘.
```

**완성 예시** (동네 카페 "커피한잔")

```text
우리 가게 월 고정비야:
- 임대료: [금액]원
- 인건비: [금액]원
- 공과금(전기·수도·가스·통신): [금액]원
- 기타 고정비(보험, 구독, 대출이자 등): [금액]원

대표 메뉴 아메리카노의 판매가는 4,000원, 1인분 재료 원가는 [위에서 계산한 값]원이야.

해줄 것:
1. 월 고정비 합계
2. 1인분당 이익(판매가 - 재료 원가)
3. 손익분기 판매 수량 = 월 고정비 ÷ 1인분당 이익
4. 손익분기 매출 = 손익분기 수량 × 판매가
5. 한 달 26일 기준 하루에 몇 인분을 팔아야 하는지
계산 과정을 한 줄씩 보여줘. 결과는 표로 정리해줘.
```

고정비 금액은 가게마다 완전히 다르므로 예시에도 빈칸으로 뒀습니다. 사장님 숫자를 넣으세요.

**예상 결과**

"한 달에 N잔, 하루에 M잔 팔아야 본전"이라는 숫자가 나옵니다. 메뉴가 하나뿐인 가게는 없으니 대략적인 감을 잡는 용도입니다.

**다듬는 법**

```text
실제로는 아메리카노 말고 라떼([판매가]원, 원가 [원가]원)도 하루 [수량]잔 팔려. 두 메뉴를 합쳐서 다시 계산해줘.
```

{{< callout type="error" >}}
손익분기 수량 = 고정비 ÷ 1인분 이익. 이 나눗셈 하나는 반드시 계산기로 검산하세요. 여기가 틀리면 아래 숫자가 전부 틀립니다.
{{< /callout >}}

## 이건 나중에: 세트 메뉴 구성 제안 (2분)

원가표가 있어야 의미 있는 작업입니다. 위 단계를 마친 뒤에 하세요.

**복붙 프롬프트**

```text
우리 가게 메뉴와 원가야 (메뉴명 / 판매가 / 1인분 원가):
[메뉴 목록 붙여넣기]

세트 메뉴 3개를 제안해줘.
조건:
- 각 세트는 2–3개 메뉴 조합
- 단품 합계보다 [할인 폭]원 정도 싸게
- 세트 원가율이 단품 평균 원가율보다 나빠지지 않게
- 표 항목: 세트 이름, 구성, 세트 가격, 세트 원가, 원가율, 단품 대비 손님 절약액
계산 과정을 보여줘. 세트 이름은 손님이 보고 바로 이해할 수 있게.
```

**완성 예시** (분식집 "행복분식")

```text
우리 가게 메뉴와 원가야 (메뉴명 / 판매가 / 1인분 원가):
떡볶이 / 4,500원 / [원가]원
김밥 / 3,500원 / [원가]원
순대 / 4,000원 / [원가]원
어묵 / 1,000원 / [원가]원

세트 메뉴 3개를 제안해줘.
조건:
- 각 세트는 2–3개 메뉴 조합
- 단품 합계보다 500원 정도 싸게
- 세트 원가율이 단품 평균 원가율보다 나빠지지 않게
- 표 항목: 세트 이름, 구성, 세트 가격, 세트 원가, 원가율, 단품 대비 손님 절약액
계산 과정을 보여줘. 세트 이름은 손님이 보고 바로 이해할 수 있게.
```

**예상 결과**

세트 3개와 비교표가 나옵니다. 원가율이 낮은 메뉴(음료, 사이드)를 끼워 넣는 제안이 많이 나옵니다. 그게 맞는 방향입니다.

**다듬는 법**

```text
2번 세트는 주방에서 동시에 만들기 어려워. 조리 시간이 비슷한 메뉴끼리 다시 묶어줘.
```

## 흔한 실수

1. **검산 안 하기.** AI는 1kg을 100g으로 계산하고도 태연합니다. 계산식 칸에서 하나만 골라 계산기로 확인하세요.
2. **메뉴 10개를 한 번에 넣기.** 표가 길어질수록 실수가 늘어납니다. 대표 메뉴 3개까지만 한 번에, 나머지는 새 채팅에서.
3. **AI가 제안한 가격을 그대로 쓰기.** "손님이 받아들일 것"이라는 말은 추측입니다. 동네 시세와 사장님 감각이 우선입니다.

{{< callout type="warning" >}}
**무시해도 되는 것**
- 감가상각, 기회비용 같은 회계 용어. AI가 언급해도 지금은 넘어가세요.
- 엑셀 함수를 만들어 달라고 하는 것. 표로 받아서 메모앱에 저장하면 충분합니다. (수식이 필요해지면 2교시 5장 참고)
- 소수점 둘째 자리. 원 단위로 반올림해서 보세요.
{{< /callout >}}
