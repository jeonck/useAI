⏱ **소요 시간:** 10분

✅ **이 페이지를 끝내면 할 수 있는 것**
- 오픈·마감 체크리스트와 신입 첫날 매뉴얼을 뽑아서 주방이나 카운터에 붙입니다.
- 컴플레인 응대 스크립트를 직원에게 나눠 줍니다.
- 근무 조건을 넣으면 스케줄 초안이, 시급·시간을 넣으면 알바 공고문이 나옵니다.

{{< callout type="error" >}}
**직원 개인정보를 넣지 마세요.** 주민등록번호, 전화번호, 집 주소, 계좌번호, 실명은 절대 입력하지 마세요. 스케줄을 짤 때도 "A, B, C" 또는 "김OO"처럼 바꿔서 쓰세요. 한 번 넣은 내용은 되돌리기 어렵습니다.
{{< /callout >}}

## 무엇부터: 오픈·마감 체크리스트 (2분)

**복붙 프롬프트**

```text
[컨텍스트 카드 붙여넣기]

우리 가게 오픈 체크리스트와 마감 체크리스트를 만들어줘.
조건:
- 각각 10–15개 항목, 순서대로
- 항목마다 앞에 □ 체크박스
- 신입도 보고 바로 할 수 있게 구체적으로 (예: "청소" 말고 "테이블 6개 물티슈로 닦기")
- 우리 가게에 있는 장비: [장비 목록]
- 마지막 줄에 "완료 확인: 이름 ____ 시간 ____"
A4 한 장에 들어가게.
```

**완성 예시** (동네 카페 "커피한잔")

```text
[컨텍스트 카드 붙여넣기]

우리 가게 오픈 체크리스트와 마감 체크리스트를 만들어줘.
조건:
- 각각 10–15개 항목, 순서대로
- 항목마다 앞에 □ 체크박스
- 신입도 보고 바로 할 수 있게 구체적으로 (예: "청소" 말고 "테이블 6개 물티슈로 닦기")
- 우리 가게에 있는 장비: 에스프레소 머신 1대, 그라인더 2대, 제빙기, 쇼케이스 냉장고, 포스기
- 마지막 줄에 "완료 확인: 이름 ____ 시간 ____"
A4 한 장에 들어가게.
```

**예상 결과**

□ 표시가 붙은 두 개의 목록이 나옵니다. 장비 이름이 그대로 들어가 있습니다.

**다듬는 법**

우리 가게에 없는 항목은 지우고, 빠진 건 이렇게 추가하세요.

```text
마감에 "포스기 정산 출력해서 서랍에 넣기"와 "간판 조명 끄기" 추가해줘. "화분 물 주기"는 빼줘.
```

복사해서 메모앱이나 문서 앱에 붙여 넣고 출력하면 끝입니다.

## 그다음: 신입 첫날 매뉴얼 (2분)

**복붙 프롬프트**

```text
[컨텍스트 카드 붙여넣기]

신입 직원 첫날 교육 매뉴얼을 만들어줘.
조건:
- 첫날 [근무 시간]시간 동안 배울 것을 시간 순서로
- 오전: 인사말, 복장, 동선, 위생 규칙
- 중간: 가장 많이 나가는 메뉴 [메뉴 3개] 만드는 법 또는 응대 순서
- 마지막: 첫날 꼭 외워야 할 것 5개
- 말투는 신입에게 직접 말하듯이 ("~하세요")
- 하지 말아야 할 것 3개도 따로
```

**완성 예시** (미용실 "헤어살롱 봄")

```text
[컨텍스트 카드 붙여넣기]

신입 직원 첫날 교육 매뉴얼을 만들어줘.
조건:
- 첫날 6시간 동안 배울 것을 시간 순서로
- 오전: 인사말, 복장, 동선, 위생 규칙
- 중간: 가장 많이 하는 일 3개(샴푸 보조, 예약 전화 받기, 도구 소독) 순서
- 마지막: 첫날 꼭 외워야 할 것 5개
- 말투는 신입에게 직접 말하듯이 ("~하세요")
- 하지 말아야 할 것 3개도 따로
```

**예상 결과**

시간대별 교육 순서와 "꼭 외울 것 5개", "하지 말 것 3개"가 나옵니다. 메뉴 만드는 법은 AI가 일반적인 방법을 씁니다. 우리 가게 레시피와 다르면 고쳐야 합니다.

**다듬는 법**

```text
우리 가게는 [우리만의 규칙]이야. 그 부분을 반영해서 다시 써줘.
```

예: "우리 가게는 손님이 들어오면 무조건 먼저 물을 갖다 드려" 같은 규칙.

## 그다음: 컴플레인 응대 스크립트 (2분)

**복붙 프롬프트**

```text
[컨텍스트 카드 붙여넣기]

직원용 컴플레인 응대 스크립트를 만들어줘.
자주 생기는 상황 [상황 3개]에 대해 각각:
1. 첫마디 (사과 + 상황 확인)
2. 해결 제안 (직원이 결정할 수 있는 범위: [권한 범위])
3. 사장 호출 기준 (이럴 땐 직원이 처리하지 말고 사장을 부른다)
말투는 실제로 입으로 말하는 문장으로. 각 상황당 5줄 이내.
```

**완성 예시** (동네 카페 "커피한잔")

```text
[컨텍스트 카드 붙여넣기]

직원용 컴플레인 응대 스크립트를 만들어줘.
자주 생기는 상황 3개(음료가 주문과 다름, 음료에 이물질, 대기 시간이 너무 길다)에 대해 각각:
1. 첫마디 (사과 + 상황 확인)
2. 해결 제안 (직원이 결정할 수 있는 범위: 재제조, 무료 쿠폰 1장까지)
3. 사장 호출 기준 (이럴 땐 직원이 처리하지 말고 사장을 부른다)
말투는 실제로 입으로 말하는 문장으로. 각 상황당 5줄 이내.
```

**예상 결과**

상황별로 "죄송합니다, 어떤 음료 주문하셨죠?" 같은 실제 대사가 나옵니다. "사장 호출 기준"에 환불 요구, 신체 피해 언급 같은 항목이 들어갑니다.

**다듬는 법**

```text
말투가 너무 딱딱해. 동네 카페답게 조금 더 부드럽게, 하지만 과하게 굽신거리지 않게.
```

## 그다음: 근무 스케줄 초안 (2분)

**복붙 프롬프트**

```text
다음 조건으로 [기간] 근무 스케줄 초안을 표로 만들어줘.
- 영업시간: [요일별 영업시간]
- 직원: A([가능 요일·시간]), B([가능 요일·시간]), C([가능 요일·시간])
- 시간대별 최소 인원: [예: 점심 12–14시 2명, 그 외 1명]
- 각 직원 주당 최대 [시간]시간
- 연속 근무 [일수]일 넘지 않게
표 항목: 요일, 시간대, 근무자. 조건을 못 맞춘 칸은 "조정 필요"라고 표시해줘.
```

**완성 예시** (동네 카페 "커피한잔")

```text
다음 조건으로 다음 주 월~일 근무 스케줄 초안을 표로 만들어줘.
- 영업시간: 평일 8–20시, 주말 10–20시
- 직원: A(평일 오전만 가능), B(평일 오후·주말 가능), C(주말만 가능)
- 시간대별 최소 인원: 점심 12–14시 2명, 그 외 1명 (사장은 항상 있음)
- 각 직원 주당 최대 20시간
- 연속 근무 5일 넘지 않게
표 항목: 요일, 시간대, 근무자. 조건을 못 맞춘 칸은 "조정 필요"라고 표시해줘.
```

**예상 결과**

요일×시간대 표에 A, B, C가 배치됩니다. "조정 필요" 칸이 생기면 인원이 부족하다는 신호입니다.

**다듬는 법**

```text
B가 수요일은 안 된대. 수요일 오후를 다시 짜고, B의 주당 시간이 20시간 안 넘는지 다시 세어줘.
```

직원 이름은 끝까지 A, B, C로 두세요. 출력해서 붙일 때 사장님이 손으로 이름을 쓰면 됩니다.

## 이건 나중에: 아르바이트 공고문 (2분)

**복붙 프롬프트**

```text
[컨텍스트 카드 붙여넣기]

아르바이트 채용 공고문을 써줘.
- 근무 요일·시간: [요일·시간]
- 시급: [시급]원 (주휴수당 등 법정 조건은 "관련 법에 따름"이라고만)
- 하는 일: [주요 업무 3개]
- 우대: [우대 조건]
- 지원 방법: [방법]
조건: 200자 이내, 첫 줄에 가장 중요한 정보(요일·시간), 과장 없이, 존댓말.
알바 구인 사이트에 바로 올릴 수 있는 형태로.
```

**완성 예시** (동네 카페 "커피한잔")

```text
[컨텍스트 카드 붙여넣기]

아르바이트 채용 공고문을 써줘.
- 근무 요일·시간: 토·일 10–16시
- 시급: [시급]원 (주휴수당 등 법정 조건은 "관련 법에 따름"이라고만)
- 하는 일: 음료 제조, 주문 받기, 매장 정리
- 우대: 카페 경험자, 6개월 이상 근무 가능자
- 지원 방법: 매장 방문 또는 문자
조건: 200자 이내, 첫 줄에 가장 중요한 정보(요일·시간), 과장 없이, 존댓말.
알바 구인 사이트에 바로 올릴 수 있는 형태로.
```

**예상 결과**

200자 안팎의 공고문이 나옵니다. "따뜻한 분위기", "가족 같은" 같은 말이 들어가면 빼세요. 요즘 지원자는 그 말을 싫어합니다.

**다듬는 법**

```text
"가족 같은", "열정" 같은 표현 빼고, 대신 휴게 시간과 식사 제공 여부를 넣어줘.
```

{{< callout type="error" >}}
시급, 주휴수당, 4대보험 등 채용 조건은 법이 정한 최저 기준이 있습니다. AI가 쓴 문구를 올리기 전에 고용노동부 공식 사이트에서 올해 기준을 확인하거나 노무사에게 물어보세요. [5번 페이지](../05-tax-labor-contract)에서 질문 정리법을 다룹니다.
{{< /callout >}}

## 흔한 실수

1. **직원 실명·전화번호를 넣기.** 스케줄 짤 때 특히 자주 실수합니다. A, B, C로 바꾸세요.
2. **AI 매뉴얼을 그대로 붙이기.** 레시피, 동선, 규칙은 가게마다 다릅니다. 신입 매뉴얼은 사장님이 한 번 읽고 고친 뒤에 주세요.
3. **공고문의 근로 조건을 확인 없이 올리기.** 시급·수당은 법정 기준이 있습니다. 확인 후 게시하세요.

{{< callout type="warning" >}}
**무시해도 되는 것**
- 직원 평가표, KPI, 인사 제도 같은 큰 회사 용어. AI가 제안해도 지금 가게에는 필요 없습니다.
- 스케줄 자동화 앱 추천. 표 하나로 시작하세요.
- 교육 영상 대본 만들기. 종이 한 장이면 충분합니다.
{{< /callout >}}
