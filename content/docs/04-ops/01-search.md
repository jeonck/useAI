⏱ **소요 시간:** 8분

✅ **이 페이지를 끝내면 할 수 있는 것**
- "웹 검색" 기능을 켜서 오늘 기준 최신 정보(지원사업 공고, 원자재 시세, 경쟁 매장 동향)를 출처 링크와 함께 받습니다.
- AI가 지어낸 답을 3가지 방법으로 걸러냅니다.
- 네이버로 찾을 것과 ChatGPT로 찾을 것을 구분합니다.

## 무엇부터: 웹 검색 켜기 (1분)

ChatGPT는 기본적으로 "예전에 배운 내용"으로 답합니다. 최신 정보는 모릅니다. 그래서 **웹 검색**을 켜야 합니다.

{{% steps %}}

### 1단계. 입력창 근처 버튼 찾기

입력창 왼쪽 아래(스마트폰은 입력창 옆 "+" 버튼 안)에 "**검색**" 또는 지구본 모양 버튼이 있습니다. 누르면 켜집니다.

### 2단계. 켜졌는지 확인

버튼에 색이 들어오거나 "검색" 글자가 입력창에 표시됩니다. 이 상태에서 질문하면 인터넷을 뒤져서 답합니다.

### 3단계. 프롬프트에도 한 줄 추가

버튼을 못 찾겠으면 프롬프트 첫 줄에 "**웹 검색해서 답해줘**" 라고 쓰세요. 대부분 알아서 검색합니다.

{{% /steps %}}

{{< callout type="info" >}}
버튼 위치와 이름은 앱 업데이트마다 조금씩 바뀝니다. "검색", "웹 검색", 지구본 아이콘 셋 중 하나를 찾으세요. 못 찾으면 3단계 방법으로 충분합니다.
{{< /callout >}}

## 그다음: 지원사업 공고 찾기 (2분)

**복붙 프롬프트**

```text
웹 검색해서 답해줘.
나는 [지역]에서 [업종]을 운영하는 소상공인이야.
지금 신청할 수 있는 소상공인 지원사업을 찾아줘.
조건:
- 접수 기간이 아직 안 끝난 것만
- 각 항목마다 주관 기관, 접수 마감일, 공식 링크를 반드시 적어줘
- 확실하지 않으면 "확인 필요"라고 표시해줘
```

**완성 예시** (동네 카페 "커피한잔")

```text
웹 검색해서 답해줘.
나는 서울 마포구에서 동네 카페를 운영하는 소상공인이야.
지금 신청할 수 있는 소상공인 지원사업을 찾아줘.
조건:
- 접수 기간이 아직 안 끝난 것만
- 각 항목마다 주관 기관, 접수 마감일, 공식 링크를 반드시 적어줘
- 확실하지 않으면 "확인 필요"라고 표시해줘
```

**예상 결과**

지원사업 이름, 주관 기관, 마감일, 링크가 목록으로 나옵니다. 답 끝이나 문장 옆에 작은 출처 표시(숫자나 링크 아이콘)가 붙습니다.

**다듬는 법**

링크를 눌러서 실제 공고 페이지가 열리는지 확인하세요. 안 열리거나 다른 내용이면 이렇게 이어 쓰세요.

```text
2번 링크가 안 열려. 공식 사이트(소상공인시장진흥공단, 지자체 홈페이지)에서 다시 찾아줘.
```

## 그다음: 지어낸 답 구별법 (2분)

AI는 모르는 것도 아는 척 답합니다. 웹 검색을 켜도 완전히 없어지지 않습니다. 이 3가지를 습관으로 만드세요.

**1. 날짜와 출처를 물어보세요.**

```text
방금 답한 내용의 출처 링크와 그 자료의 작성 날짜를 항목마다 적어줘. 출처가 없는 항목은 "출처 없음"이라고 표시해줘.
```

"출처 없음"이 붙은 항목은 믿지 마세요.

**2. 두 번 물어보세요.**

새 채팅을 열고 같은 질문을 다시 하세요. 두 답이 다르면 둘 다 확인이 필요한 겁니다. 특히 숫자·날짜·기관 이름이 달라지면 지어낸 것일 가능성이 큽니다.

**3. 링크를 눌러보세요.**

출처 링크가 안 열리거나, 열었는데 그 내용이 없으면 지어낸 겁니다. 링크 확인은 10초면 됩니다.

{{< callout type="error" >}}
지원금 금액, 마감일, 세율, 법 조항처럼 틀리면 손해 보는 정보는 ChatGPT 답을 그대로 믿지 마세요. 반드시 공식 사이트(정부24, 소상공인시장진흥공단, 국세청, 지자체 홈페이지)에서 원문을 확인하세요.
{{< /callout >}}

## 네이버와 역할 분담 (1분)

| 이럴 때 | 이걸로 |
|---|---|
| 우리 동네 가게 위치·영업시간·리뷰 | **네이버 지도** |
| 특정 상품 최저가, 배달앱 순위 | **네이버 쇼핑, 배달앱** |
| 오늘 뉴스 한 건 빨리 보기 | **네이버 뉴스** |
| 흩어진 정보를 "정리해서" 받기 (지원사업 목록, 시세 흐름 요약) | **ChatGPT 웹 검색** |
| 찾은 정보를 우리 가게에 적용하면 어떻게 되는지 | **ChatGPT** (검색 결과 붙여넣고 질문) |

핵심은 이겁니다. **네이버는 찾는 도구, ChatGPT는 정리하고 적용하는 도구.** 네이버에서 찾은 글을 복사해서 ChatGPT에 붙여 넣고 "우리 가게 기준으로 요약해줘"라고 하면 둘의 장점이 합쳐집니다.

## 흔한 실수

1. **웹 검색 안 켜고 "요즘"을 묻기.** 몇 년 전 정보를 오늘 것처럼 답합니다. "최신", "지금", "올해"가 들어가는 질문은 무조건 켜세요.
2. **출처 링크 안 눌러보기.** 링크가 붙어 있어도 내용이 다를 수 있습니다. 돈이 걸린 정보는 반드시 눌러서 확인하세요.
3. **동네 단위 정보를 기대하기.** "우리 옆 가게 요즘 뭐 팔아?"는 못 찾습니다. 업종 흐름까지만 기대하세요.

{{< callout type="warning" >}}
**무시해도 되는 것**
- "딥 리서치", "심층 조사" 같은 고급 검색 기능. 지금은 기본 웹 검색으로 충분합니다.
- 검색 결과가 몇 개 사이트에서 왔는지 세는 것. 링크가 열리고 내용이 맞으면 됩니다.
- 영어 자료를 찾아 달라고 하는 것. 한국 지원사업·시세는 한국어로 물어야 정확합니다.
{{< /callout >}}
