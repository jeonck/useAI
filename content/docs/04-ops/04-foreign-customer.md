⏱ **소요 시간:** 10분

✅ **이 페이지를 끝내면 할 수 있는 것**
- 메뉴판을 영어·일본어·중국어로, 음식 설명까지 붙여서 번역합니다.
- 응대 문장 10개 카드와 알레르기 안내문을 만들어 카운터에 둡니다.
- 스마트폰 음성 모드로 외국인 손님과 실시간 통역 대화를 합니다.

## 무엇부터: 메뉴판 3개 국어 번역 (3분)

메뉴 이름만 번역하면 외국인은 뭔지 모릅니다. "설명 한 줄"이 핵심입니다.

**복붙 프롬프트**

```text
[컨텍스트 카드 붙여넣기]

우리 가게 메뉴판을 영어, 일본어, 중국어(간체)로 번역해줘.
메뉴 목록 (메뉴명 / 가격 / 주재료·특징):
[메뉴 목록 붙여넣기]

조건:
- 표로: 한국어 메뉴명 | 영어 | 일본어 | 중국어 | 가격
- 각 언어 아래에 외국인이 이해할 수 있는 한 줄 설명 (예: 떡볶이 → "spicy rice cakes in sweet chili sauce")
- 고유 음식명은 발음 그대로 쓰고 괄호에 설명 (예: Tteokbokki)
- 매운 정도, 뜨거움, 양 같은 정보가 있으면 표시
- 가격은 원화 그대로, 숫자 바꾸지 말 것
```

**완성 예시** (분식집 "행복분식")

```text
[컨텍스트 카드 붙여넣기]

우리 가게 메뉴판을 영어, 일본어, 중국어(간체)로 번역해줘.
메뉴 목록 (메뉴명 / 가격 / 주재료·특징):
떡볶이 / 4,500원 / 쌀떡, 어묵, 고추장 소스, 매움
김밥 / 3,500원 / 밥, 단무지, 당근, 시금치, 계란, 햄
순대 / 4,000원 / 돼지 창자에 당면·선지, 소금 찍어 먹음
어묵탕 / 3,000원 / 어묵, 무, 멸치 국물, 뜨거움

조건:
- 표로: 한국어 메뉴명 | 영어 | 일본어 | 중국어 | 가격
- 각 언어 아래에 외국인이 이해할 수 있는 한 줄 설명 (예: 떡볶이 → "spicy rice cakes in sweet chili sauce")
- 고유 음식명은 발음 그대로 쓰고 괄호에 설명 (예: Tteokbokki)
- 매운 정도, 뜨거움, 양 같은 정보가 있으면 표시
- 가격은 원화 그대로, 숫자 바꾸지 말 것
```

**예상 결과**

3개 국어 표와 설명이 나옵니다. 순대처럼 설명이 어려운 음식은 "blood sausage"처럼 직설적으로 나올 수 있습니다. 손님이 거부감을 느낄 것 같으면 다듬으세요.

**다듬는 법**

```text
순대 설명이 너무 직설적이야. 외국인이 시도해 보고 싶게 부드럽게 바꿔줘. 거짓말은 하지 말고.
```

번역 결과를 확인할 방법이 없다고 걱정하지 마세요. 새 채팅을 열고 번역문만 붙여 넣은 뒤 "**이걸 한국어로 다시 번역해줘**" 라고 하면 역번역이 나옵니다. 원래 뜻과 크게 다르면 그 항목만 다시 하세요.

{{< callout type="info" >}}
가격 숫자가 바뀌지 않았는지 반드시 눈으로 확인하세요. 번역 중에 숫자가 바뀌는 일이 가끔 있습니다.
{{< /callout >}}

## 그다음: 응대 문장 10개 카드 (2분)

카운터에 두고 손가락으로 가리키며 쓰는 카드입니다.

**복붙 프롬프트**

```text
[업종] 가게에서 외국인 손님에게 가장 자주 쓰는 문장 10개를 골라줘.
각 문장을 한국어 | 영어 | 일본어 | 중국어 표로.
포함할 상황: 인사, 주문 받기, 매운 정도 묻기, 포장/매장 묻기, 결제 방법 안내, 대기 시간 안내, 화장실 위치, 감사 인사.
우리 가게 특이사항: [특이사항]
조건: 문장은 짧게, 손님이 읽고 바로 이해할 수 있게. 표 아래에 손님이 답할 때 쓸 "네/아니오/조금/많이" 4단어도 4개 국어로.
```

**완성 예시** (분식집 "행복분식")

```text
분식집에서 외국인 손님에게 가장 자주 쓰는 문장 10개를 골라줘.
각 문장을 한국어 | 영어 | 일본어 | 중국어 표로.
포함할 상황: 인사, 주문 받기, 매운 정도 묻기, 포장/매장 묻기, 결제 방법 안내, 대기 시간 안내, 화장실 위치, 감사 인사.
우리 가게 특이사항: 선불, 카드 가능, 화장실은 건물 2층
조건: 문장은 짧게, 손님이 읽고 바로 이해할 수 있게. 표 아래에 손님이 답할 때 쓸 "네/아니오/조금/많이" 4단어도 4개 국어로.
```

**예상 결과**

10행짜리 4개 국어 표가 나옵니다. 출력해서 코팅하면 카드가 됩니다.

**다듬는 법**

```text
"현금만 가능해요"가 빠졌어. 추가하고, 표를 A5 크기에 맞게 글자 수를 줄여줘.
```

## 그다음: 알레르기 안내 (2분)

외국인 손님은 알레르기를 훨씬 자주 물어봅니다. 미리 준비하면 응대가 쉬워집니다.

**복붙 프롬프트**

```text
우리 가게 메뉴별 알레르기 유발 재료 안내표를 만들어줘.
메뉴와 재료:
[메뉴명 / 들어가는 재료 전부]

조건:
- 표: 메뉴명 | 포함 재료(한/영/일/중) 
- 흔한 알레르기 항목(땅콩, 견과류, 우유, 계란, 밀, 대두, 갑각류, 생선, 조개류)이 들어가면 굵게 표시
- 표 위에 "알레르기가 있으면 주문 전 말씀해 주세요" 문장을 4개 국어로
- 내가 안 적은 재료를 추측해서 넣지 말 것. 모르면 "확인 필요"
```

**완성 예시** (동네 카페 "커피한잔")

```text
우리 가게 메뉴별 알레르기 유발 재료 안내표를 만들어줘.
메뉴와 재료:
카페라떼 / 에스프레소, 우유
아몬드라떼 / 에스프레소, 아몬드 우유
크로플 / 밀가루, 버터, 계란, 설탕, 메이플 시럽
치즈케이크 / 크림치즈, 계란, 밀가루, 설탕, 생크림

조건:
- 표: 메뉴명 | 포함 재료(한/영/일/중) 
- 흔한 알레르기 항목(땅콩, 견과류, 우유, 계란, 밀, 대두, 갑각류, 생선, 조개류)이 들어가면 굵게 표시
- 표 위에 "알레르기가 있으면 주문 전 말씀해 주세요" 문장을 4개 국어로
- 내가 안 적은 재료를 추측해서 넣지 말 것. 모르면 "확인 필요"
```

**예상 결과**

메뉴별 재료 표에 알레르기 항목이 굵게 표시됩니다.

**다듬는 법**

```text
소스나 시럽에 들어가는 재료는 내가 확인해서 알려줄게. [소스명]에는 [재료]가 들어가. 반영해서 다시 만들어줘.
```

{{< callout type="error" >}}
알레르기 표는 사장님이 재료 포장의 원재료 표시를 직접 보고 만든 목록이 기준입니다. AI는 재료를 "추측"할 수 있습니다. 시판 소스·시럽·빵은 원재료 라벨을 꼭 확인하세요. 잘못된 안내는 손님 건강과 직결됩니다.
{{< /callout >}}

## 그다음: 실시간 통역 — 음성 모드 (2분)

카드로 안 되는 상황(복잡한 주문, 컴플레인)이면 스마트폰을 꺼내세요.

{{% steps %}}

### 1단계. 음성 모드 켜기

ChatGPT 앱 입력창 오른쪽의 **음성 모드** 버튼(헤드폰 또는 물결 모양)을 누릅니다. 마이크 버튼(받아쓰기)과 다릅니다. 음성 모드는 대화가 계속 이어집니다.

### 2단계. 첫마디로 역할 정하기

음성 모드가 켜지면 한국어로 이렇게 말하세요.

```text
지금부터 통역해줘. 내가 한국어로 말하면 영어로 바꿔서 말해주고, 손님이 영어로 말하면 한국어로 바꿔서 말해줘. 다른 말은 하지 마.
```

손님이 일본어·중국어면 "영어" 자리에 그 언어를 넣으세요. 어떤 언어인지 모르면 "손님이 쓰는 언어로"라고 하면 됩니다.

### 3단계. 스마트폰을 사이에 두고 번갈아 말하기

사장님이 말하고 잠깐 멈추면 통역이 나옵니다. 손님이 말하면 한국어로 들립니다. 한 번에 한 문장씩, 짧게 말하세요.

### 4단계. 끝나면 종료

화면의 X 또는 종료 버튼을 누릅니다.

{{% /steps %}}

{{< callout type="info" >}}
시끄러운 매장에서는 잘 못 알아듣습니다. 스마트폰을 입 가까이 대고, 주변 음악은 잠깐 줄이세요. 미리 한 번 혼자 연습해 두면 실전에서 당황하지 않습니다.
{{< /callout >}}

## 이건 나중에: 관광객용 안내문 (1분)

관광지 근처 가게라면 만들어 두세요. 아니면 건너뛰세요.

**복붙 프롬프트**

```text
[컨텍스트 카드 붙여넣기]

가게 입구에 붙일 외국인 관광객용 안내문을 영어, 일본어, 중국어로 써줘.
넣을 내용:
- 영업시간: [영업시간]
- 주문 방법: [예: 카운터 선주문, 테이블 QR 주문]
- 결제: [카드/현금/해외카드 가능 여부]
- 우리 가게 대표 메뉴 1개 추천: [메뉴명]
- [기타: 포장 가능, 와이파이, 콘센트, 반려동물 등]
조건: 각 언어 5줄 이내. 환영하는 톤이지만 짧게.
```

**완성 예시** (동네 카페 "커피한잔")

```text
[컨텍스트 카드 붙여넣기]

가게 입구에 붙일 외국인 관광객용 안내문을 영어, 일본어, 중국어로 써줘.
넣을 내용:
- 영업시간: 매일 8시~20시
- 주문 방법: 카운터에서 먼저 주문, 진동벨로 호출
- 결제: 카드, 현금, 해외 카드 가능
- 우리 가게 대표 메뉴 1개 추천: 흑임자 라떼
- 포장 가능, 무료 와이파이
조건: 각 언어 5줄 이내. 환영하는 톤이지만 짧게.
```

**예상 결과**

언어별 5줄 안내문이 나옵니다. 출력해서 입구에 붙이면 됩니다.

**다듬는 법**

```text
"흑임자"를 외국인이 이해할 수 있게 괄호로 설명 붙여줘. 영어는 black sesame인 거 알아.
```

## 흔한 실수

1. **메뉴 이름만 번역하기.** "Sundae"라고 써 놓으면 아이스크림인 줄 압니다. 설명 한 줄이 핵심입니다.
2. **번역 결과를 확인 안 하기.** 역번역(다시 한국어로) 한 번이면 큰 오류는 잡힙니다. 가격 숫자는 눈으로 확인하세요.
3. **알레르기 표를 AI 추측으로 만들기.** 재료는 사장님이 적은 것만 들어가야 합니다. "확인 필요"가 남아 있으면 게시하지 마세요.

{{< callout type="warning" >}}
**무시해도 되는 것**
- 번체·간체, 관서·관동 사투리 같은 세부 구분. 중국어는 간체, 일본어는 표준어면 충분합니다.
- 메뉴판 디자인·인쇄 방법. 표를 복사해서 문서 앱에 붙이고 출력하면 됩니다.
- 음성 모드의 목소리 종류 선택. 기본값으로 두세요.
{{< /callout >}}
