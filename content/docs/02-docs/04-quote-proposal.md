⏱ 소요 시간: 12분

✅ 이 페이지를 끝내면 할 수 있는 것
- 견적서 항목을 표로 받아 엑셀·한글에 그대로 붙입니다.
- 납품 제안서 1장을 구조 잡아 30분 안에 완성합니다.
- 소상공인 지원사업 신청서 문항의 초안 구조를 받고, 사실과 숫자만 직접 채웁니다.

{{< callout type="error" >}}
이 페이지에서 가장 중요한 경고입니다. **AI는 숫자를 지어냅니다.** 매출, 원가, 인건비, 시장 규모, 성장률을 물어보지 않아도 그럴듯하게 채워 넣습니다. AI가 쓴 숫자를 그대로 제출하면 신청서는 허위가 되고, 견적서는 손해가 됩니다. **모든 숫자는 사장님이 직접 채우고, AI는 빈칸이 있는 구조만 받으세요.**
{{< /callout >}}

## 먼저: 이 페이지의 원칙 한 줄

> 구조·문장·순서는 AI. 숫자·사실·약속은 사장님.

프롬프트마다 "숫자는 [빈칸]으로 남겨"를 넣습니다. 이 한 줄이 이 페이지의 전부입니다.

## 1. 견적서 — 항목을 표로 받기

견적서 서식은 이미 있을 겁니다(엑셀, 한글, 세무 프로그램). AI에게 시킬 건 **빠뜨린 항목 없이 표로 정리**하는 것.

{{% steps %}}

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

[무엇]에 대한 견적서 항목을 표로 정리해 줘.
- 표 열: 번호 | 항목 | 규격/내용 | 수량 | 단가 | 금액 | 비고
- 단가·금액은 전부 [빈칸]으로 남겨. 숫자를 지어내지 마.
- 내가 빠뜨리기 쉬운 항목(배송비, 설치비, 부가세, 추가 옵션)이 있으면 마지막 줄에 "확인 필요"로 추가해.
- 표 아래에 "견적 유효기간, 결제 조건, 납기" 3줄 자리 만들어 줘.

포함할 항목:
[사장님이 아는 항목을 줄글로]
```

### 업종 예시 완성본 (소규모 제조 "행복문구")

```text
우리 가게: 행복문구. 문구류 소규모 제조·도매. 주 거래처는 학원·회사 판촉물.

학원 판촉용 볼펜 500개 주문에 대한 견적서 항목을 표로 정리해 줘.
- 표 열: 번호 | 항목 | 규격/내용 | 수량 | 단가 | 금액 | 비고
- 단가·금액은 전부 [빈칸]으로 남겨. 숫자를 지어내지 마.
- 내가 빠뜨리기 쉬운 항목(배송비, 설치비, 부가세, 추가 옵션)이 있으면 마지막 줄에 "확인 필요"로 추가해.
- 표 아래에 "견적 유효기간, 결제 조건, 납기" 3줄 자리 만들어 줘.

포함할 항목:
볼펜 본체 500개(검정, 0.5mm), 1도 로고 인쇄, 개별 OPP 포장, 박스 포장 5박스, 서울 시내 배송.
```

### 예상 결과

7열 표에 항목 5–6줄, 단가·금액은 [빈칸]. 마지막에 "인쇄 판비(초도), 부가세 별도 여부 — 확인 필요"가 붙습니다.

### 다듬는 법

- 표를 복사해 엑셀에 붙이면 열이 그대로 나뉩니다. 안 나뉘면 "탭으로 구분된 형식으로 다시 줘".
- 항목이 너무 잘게 쪼개지면: "인쇄 관련 항목은 1줄로 합쳐."

{{% /steps %}}

## 2. 납품 제안서 1장

거래처에 "우리 제품 써 주세요"를 A4 한 장으로. **한 장을 넘기면 안 읽힙니다.** 구조는 정해져 있습니다.

| 순서 | 내용 | 분량 |
|---|---|---|
| 1. 한 줄 제안 | 무엇을, 누구에게, 왜 좋은지 | 1문장 |
| 2. 상대의 문제 | 상대가 지금 겪는 불편 | 2문장 |
| 3. 우리 제품·서비스 | 문제를 어떻게 푸는지 | 3–4문장 |
| 4. 조건 | 가격·납기·최소 수량 (빈칸) | 표 |
| 5. 다음 행동 | 샘플 발송, 미팅 제안 | 1문장 |

```text
[컨텍스트 카드 붙여넣기]

[거래처 종류]에 보낼 납품 제안서를 A4 1장 분량으로 써 줘.
- 구조: 한 줄 제안 → 상대의 문제 2문장 → 우리 제품 3–4문장 → 조건 표 → 다음 행동 1문장
- 가격·납기·최소 수량은 [빈칸]. 숫자 지어내지 마.
- "업계 최고", "최상의 품질" 같은 근거 없는 표현 금지. 내가 준 사실만.
- 존댓말, 전체 12문장 이내.

우리 제품·서비스 사실:
[사장님이 아는 사실. 만드는 방식, 차별점, 기존 거래처 유형]
상대가 겪을 문제(추측 아닌, 들은 것):
[예: 소량 주문이 안 된다, 납기가 길다]
```

**업종 예시 완성본 (카페 "커피한잔" → 근처 사무실 정기 배달):**

```text
우리 가게: 커피한잔. 동네 카페, 오피스 상권, 직접 로스팅.

근처 사무실(20–50인 규모)에 보낼 정기 커피 배달 제안서를 A4 1장 분량으로 써 줘.
- 구조: 한 줄 제안 → 상대의 문제 2문장 → 우리 제품 3–4문장 → 조건 표 → 다음 행동 1문장
- 가격·납기·최소 수량은 [빈칸]. 숫자 지어내지 마.
- "업계 최고", "최상의 품질" 같은 근거 없는 표현 금지. 내가 준 사실만.
- 존댓말, 전체 12문장 이내.

우리 제품·서비스 사실:
매장에서 직접 로스팅, 오전 8시 30분 전 사무실 도착 배달 가능, 10잔 단위 주문, 월 단위 후불 가능.
상대가 겪을 문제(추측 아닌, 들은 것):
아침마다 직원들이 커피 사러 나가서 10–15분씩 비움. 탕비실 캡슐은 맛 불만.
```

**예상 결과:** "아침 커피 사러 나가는 15분을 돌려드립니다" 같은 한 줄 제안으로 시작, 조건 표는 [빈칸], 마지막에 "첫 주 무료 샘플 10잔" 같은 다음 행동이 붙습니다.

**다듬는 법:**
- 다음 행동에 AI가 넣은 "무료 샘플"이 사장님 계획에 없으면 바꾸세요.
- "한 줄 제안을 3가지 버전으로" 하면 첫 문장만 고를 수 있습니다.

## 3. 소상공인 지원사업 신청서 문항 답변 초안

신청서에는 "사업 개요", "추진 배경 및 필요성", "기대 효과" 같은 문항이 있습니다. 백지에서 쓰기 어렵지, **문항을 그대로 주면 AI가 구조를 잡아 줍니다.**

{{< callout type="error" >}}
신청서 답변의 AI 초안은 **구조와 문장**만 참고하세요. 매출액, 고용 인원, 투자 금액, 시장 규모, 기대 매출 증가율은 전부 사장님이 증빙 가능한 숫자로 직접 채워야 합니다. AI가 쓴 숫자를 그대로 제출하면 허위 기재가 됩니다. 사업 요건, 제출 서류, 세무·노무 관련 사항은 해당 기관 담당자와 세무사·노무사에게 확인하세요.
{{< /callout >}}

{{% steps %}}

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

소상공인 지원사업 신청서 문항에 대한 답변 초안을 써 줘.
- 문항: "[신청서 문항 그대로]"
- 글자 수 제한: [있으면]
- 구조: 현재 상황 → 문제 → 이 지원으로 할 것 → 기대 효과 순서로.
- 숫자(매출, 인원, 금액, 비율)는 전부 [빈칸: 무엇]으로 남겨. 절대 지어내지 마.
- 근거 없는 표현("급성장", "혁신적") 금지. 내가 준 사실만.
- 문어체, 신청서 톤.

우리 가게 사실:
[사장님이 아는 것. 업력, 하는 일, 지원받으면 할 일]
```

### 업종 예시 완성본 (네일샵 "미소네일")

```text
우리 가게: 미소네일. 아파트 단지 상가 네일샵, 1인 운영, 업력 3년, 예약제.

소상공인 지원사업 신청서 문항에 대한 답변 초안을 써 줘.
- 문항: "사업 추진 배경 및 필요성을 기술하시오"
- 글자 수 제한: 500자
- 구조: 현재 상황 → 문제 → 이 지원으로 할 것 → 기대 효과 순서로.
- 숫자(매출, 인원, 금액, 비율)는 전부 [빈칸: 무엇]으로 남겨. 절대 지어내지 마.
- 근거 없는 표현("급성장", "혁신적") 금지. 내가 준 사실만.
- 문어체, 신청서 톤.

우리 가게 사실:
3년간 단골 위주로 운영. 예약을 전화·카톡으로 받다 보니 중복 예약과 노쇼가 잦음. 지원금으로 온라인 예약 시스템 도입과 매장 내 대기 공간 정비를 하려 함.
```

### 예상 결과

500자 이내로, "[빈칸: 월평균 예약 건수]", "[빈칸: 월 노쇼 건수]" 같은 빈칸이 4–6개 박힌 초안. 문장은 신청서 톤으로 정리되어 있습니다.

### 다듬는 법

- 빈칸을 채운 뒤: "아래 글을 500자 안으로 다듬어 줘. 숫자는 절대 바꾸지 마."
- 문항이 여러 개면 한 번에 하나씩. 한꺼번에 넣으면 문항끼리 내용이 섞입니다.
- 빈칸으로 남긴 숫자를 사장님이 모르면, 그 숫자는 쓰지 않는 게 맞습니다. 없는 숫자를 만들어 넣는 순간부터가 문제입니다.

## 4. 사업계획서 목차만 받기

긴 사업계획서를 통째로 시키지 마세요. 나오긴 하는데 전부 지어낸 내용입니다. **목차와 각 장에 들어갈 질문**만 받고, 답은 사장님이 씁니다.

```text
[컨텍스트 카드 붙여넣기]

[용도: 은행 대출 / 지원사업 / 투자 유치 / 내부 정리]용 사업계획서 목차를 만들어 줘.
- 장별로 "이 장에서 답해야 할 질문" 3개씩.
- 각 질문 옆에 "필요한 숫자·자료"를 적어 줘.
- 내용은 쓰지 마. 목차와 질문만.
```

**예상 결과:** 6–8개 장, 각 장에 질문 3개와 "필요 자료: 최근 12개월 매출표" 같은 메모.

**다듬는 법:** 각 장에 사장님이 답을 쓰고, 그 답을 "이 내용을 사업계획서 문장으로 정리해 줘. 숫자는 바꾸지 마"로 다듬으면 끝입니다.

## 다음 순서

1. **지금 당장:** 견적서 표 프롬프트로 가장 자주 나가는 견적 하나를 정리해 두세요.
2. **그다음:** 신청서 문항 하나를 골라 빈칸 초안을 받고, 빈칸을 채워 보세요.
3. **나중에:** 사업계획서 전체는 목차만 받고, 시간 날 때 장별로 채웁니다. 하루에 끝낼 일이 아닙니다.

## 흔한 실수

1. **AI가 쓴 숫자를 그대로 낸다.** 이 페이지에서 세 번째 말합니다. 숫자는 사장님이 채웁니다.
2. **"업계 최고", "혁신적" 같은 말을 남긴다.** 심사자는 이런 말을 매일 수백 번 봅니다. 사실 한 줄이 형용사 열 개를 이깁니다.
3. **제안서를 2장, 3장으로 늘린다.** 거래처는 1장만 읽습니다. 나머지는 "자세한 내용은 미팅에서".

{{< callout type="warning" >}}
**무시해도 되는 것:** 제안서 디자인 템플릿, PPT 제작, 시장 분석 프레임워크(SWOT, 3C 등). 소상공인 신청서와 납품 제안서에는 필요 없습니다. 구조 잡고 사실 채우면 끝입니다.
{{< /callout >}}
