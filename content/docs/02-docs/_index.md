**이 교시의 목표 한 줄:** 리뷰 답글, 공지문, 거래처 문자, 견적서, 회의 메모까지 — 사장님이 매일 30분씩 붙잡던 글쓰기를 ChatGPT에게 시키고 검토만 합니다.

⏱ 총 소요 시간: 약 50분

{{< callout type="info" >}}
1교시에서 만든 **컨텍스트 카드**를 메모앱에서 열어 두세요. 이 교시의 모든 프롬프트는 맨 앞에 카드를 붙여 넣는 것으로 시작합니다.
{{< /callout >}}

## 순서대로 진행하세요

가장 자주 쓰고, 가장 빨리 효과를 보는 것부터 배웁니다.

1. [**리뷰 답글**](01-review-reply) — 8분. 매일 생기는 일이고, 오늘 저녁부터 바로 씁니다.
2. [**공지문·안내문**](02-notice) — 10분. 휴무, 가격 인상, 신메뉴. 한 번 쓰면 여러 곳에 붙입니다.
3. [**거래처·고객 문자/이메일**](03-message-email) — 12분. 미수금 독촉, 예약 확인, 사과 문자. 말투 조절이 핵심입니다.
4. [**견적서·제안서·지원사업 신청서**](04-quote-proposal) — 12분. 구조를 잡아 주면 사장님은 숫자만 채웁니다.
5. [**메모 정리·요약·엑셀 수식**](05-memo-summary) — 8분. 긴 카톡, 통화 메모, 계약서를 3줄로 줄이고, 엑셀 수식을 받아 옵니다.

## 이 교시가 끝나면

- 리뷰 10개를 한 번에 붙여 넣고 답글 10개를 받아 검토만 합니다.
- 가격 인상 안내문을 인쇄용·인스타용·카톡용 3가지 길이로 5분 안에 만듭니다.
- 미수금 독촉 문자를 "정중하지만 확실하게" 씁니다.
- 지원사업 신청서 문항의 초안 구조를 받고, 사실과 숫자만 직접 채웁니다.

{{< callout type="warning" >}}
이 교시에서는 고객 이름, 전화번호, 주소 같은 개인정보를 AI에 붙여 넣는 순간이 자주 생깁니다. 붙여 넣기 전에 반드시 지우거나 "OOO님"으로 바꾸세요. 각 페이지에 다시 한번 표시해 두었습니다.
