⏱ 소요 시간: 10분

✅ 이 페이지를 끝내면 할 수 있는 것
- 휴무 안내, 가격 인상 안내, 신메뉴 안내, 매장 규칙 안내를 5분 안에 씁니다.
- 같은 내용을 인쇄용 A4 / 인스타 스토리용 / 카톡 채널용 3가지 길이로 한 번에 받습니다.
- 가장 쓰기 어려운 "가격 인상 안내"를 손님이 납득하게 씁니다.

## 먼저: 공지문은 한 번 쓰고 세 곳에 붙입니다

공지문은 붙이는 곳마다 길이가 다릅니다. 매번 따로 쓰지 말고 **한 프롬프트에서 3가지 길이를 한꺼번에** 받으세요.

| 붙이는 곳 | 길이 | 특징 |
|---|---|---|
| 인쇄용 A4 (출입문·계산대) | 5–8문장 | 제목 크게, 날짜·시간 정확히, 서명 |
| 인스타 스토리 | 2–3줄 | 핵심 한 줄 + 날짜. 해시태그 없음 |
| 카톡 채널·문자 | 3–4문장 | 인사 1문장, 핵심, 감사 |

이 표를 프롬프트에 그대로 넣으면 됩니다. 아래 프롬프트에 이미 들어 있습니다.

## 공통 프롬프트 (모든 공지에 이 틀 하나)

```text
[컨텍스트 카드 붙여넣기]

아래 내용으로 손님 안내문을 3가지 버전으로 써 줘.
① 인쇄용 A4: 제목 + 5–8문장 + 마지막에 "[가게 이름] 드림"
② 인스타 스토리: 2–3줄, 해시태그 없이
③ 카톡 채널: 3–4문장, 인사 1문장 포함

공통 규칙:
- 존댓말. 과한 사과나 감탄사 금지.
- 날짜·시간·금액은 내가 준 것만 써. 지어내지 마.
- 손님이 궁금할 것(언제부터, 얼마나, 왜)을 빠뜨리지 마.

안내 종류: [휴무 / 가격 인상 / 신메뉴 / 매장 규칙]
내용:
[사실을 줄글로. 날짜, 시간, 금액, 이유]
```

가장 쓰기 어려운 **가격 인상 안내문**을 실제로 넣어 본 결과입니다. 변명 없이, 감사 중심으로 나옵니다.

{{< tab name="휴무 안내" >}}

**가장 쉬운 공지입니다. 여기서 프롬프트 틀을 익히세요.**

```text
우리 가게: 커피한잔. 서울 동네 상권 20석 카페, 30–40대 직장인·주부 손님.

아래 내용으로 손님 안내문을 3가지 버전으로 써 줘.
① 인쇄용 A4: 제목 + 5–8문장 + 마지막에 "커피한잔 드림"
② 인스타 스토리: 2–3줄, 해시태그 없이
③ 카톡 채널: 3–4문장, 인사 1문장 포함

공통 규칙:
- 존댓말. 과한 사과나 감탄사 금지.
- 날짜·시간·금액은 내가 준 것만 써. 지어내지 마.
- 손님이 궁금할 것(언제부터, 얼마나, 왜)을 빠뜨리지 마.

안내 종류: 휴무
내용:
10월 3일(금)~10월 5일(일) 3일간 추석 연휴 휴무. 10월 6일(월) 오전 8시 정상 영업. 연휴 전 마지막 영업은 10월 2일(목) 오후 6시까지.
```

**예상 결과:** A4용에는 "추석 연휴 휴무 안내" 제목 아래 휴무일·재개일·연휴 전 마감 시간이 다 들어갑니다. 스토리용은 "10/3(금)~10/5(일) 휴무 · 10/6(월) 8시 정상 영업" 수준의 2줄.

**다듬는 법:**
- 요일이 틀리면 사장님이 직접 확인하세요. AI는 달력을 보지 않습니다.
- "A4용 제목을 좀 더 크게 느껴지게, 짧게" 하면 제목이 4–6글자로 줄어듭니다.

{{< /tab >}}

{{< tab name="가격 인상 안내" >}}

**가장 어려운 공지입니다.** 손님이 떠나지 않게 쓰려면 3가지가 들어가야 합니다: 이유(짧게), 정확한 금액, 변하지 않는 것.

```text
우리 가게: 행복분식. 학교 앞 분식집, 떡볶이·김밥·튀김 위주, 배민 주문 비중 60%.

아래 내용으로 손님 안내문을 3가지 버전으로 써 줘.
① 인쇄용 A4: 제목 + 5–8문장 + 마지막에 "행복분식 드림"
② 인스타 스토리: 2–3줄, 해시태그 없이
③ 카톡 채널: 3–4문장, 인사 1문장 포함

공통 규칙:
- 존댓말. 과한 사과나 감탄사 금지.
- 날짜·시간·금액은 내가 준 것만 써. 지어내지 마.
- 손님이 궁금할 것(언제부터, 얼마나, 왜)을 빠뜨리지 마.
- 가격 인상 안내는 추가로: 이유는 1문장만, 변경 전/후 금액을 표로, "변하지 않는 것" 1문장 포함. 구구절절 사과하지 마.

안내 종류: 가격 인상
내용:
11월 1일부터 떡볶이 4,000원→4,500원, 김밥 3,000원→3,500원. 튀김·순대는 그대로. 이유는 쌀·식용유 등 재료비 상승. 양과 레시피는 변함 없음.
```

**예상 결과:** A4용에 변경 전/후 표가 들어가고, "양과 레시피는 그대로입니다"가 한 문장으로 들어갑니다. 이유는 "재료비 상승으로" 1문장으로 끝납니다.

**다듬는 법:**
- 사과가 너무 많으면: "죄송하다는 표현 1번으로 줄여."
- 인상 이유를 길게 늘어놓으면: "이유는 1문장. 손님은 사정 설명을 오래 읽지 않아."
- 인상 폭이 %로 나오면 지우세요. 손님에게는 금액이 훨씬 명확합니다.

{{< callout type="info" >}}
가격 인상 안내는 인상일 최소 1–2주 전에 붙이세요. 당일 붙이면 안내가 아니라 통보입니다.
{{< /callout >}}

{{< /tab >}}

{{< tab name="신메뉴·신상품 안내" >}}

**팔리는 공지입니다.** 손님이 "뭐가 좋은데?"를 3초 안에 알게 씁니다.

```text
우리 가게: 미소네일. 아파트 단지 상가 네일샵, 20–40대 여성 손님, 예약제.

아래 내용으로 손님 안내문을 3가지 버전으로 써 줘.
① 인쇄용 A4: 제목 + 5–8문장 + 마지막에 "미소네일 드림"
② 인스타 스토리: 2–3줄, 해시태그 없이
③ 카톡 채널: 3–4문장, 인사 1문장 포함

공통 규칙:
- 존댓말. 과한 사과나 감탄사 금지.
- 날짜·시간·금액은 내가 준 것만 써. 지어내지 마.
- 손님이 궁금할 것(언제부터, 얼마나, 왜)을 빠뜨리지 마.
- 신상품 안내는 추가로: 첫 문장에 손님이 얻는 것(예쁨, 편함, 오래감)을 먼저. 가격과 기간은 정확히. "지금 예약" 같은 행동 유도 1문장.

안내 종류: 신메뉴
내용:
가을 시즌 아트 "메이플 그라데이션" 출시. 기본 젤 55,000원에 아트 포함. 9월 15일~10월 31일. 오픈 기념 첫 2주(9월 15일~28일)는 5,000원 할인.
```

**예상 결과:** "손끝에 가을을" 같은 첫 줄 뒤에 가격·기간·할인 조건이 차례로 나옵니다. 스토리용은 "메이플 그라데이션 출시 · 9/15–28 5천 원 할인 · 예약 DM" 정도.

**다듬는 법:**
- 형용사가 넘치면: "형용사 절반으로. 사실 위주로."
- 할인 조건이 빠지면 다시 넣으세요. 할인 기간이 모호하면 나중에 분쟁이 됩니다.

{{< /tab >}}

{{< tab name="매장 규칙 안내" >}}

**딱딱해지기 쉬운 공지입니다.** 규칙은 명확하되, 손님을 혼내는 말투가 되지 않게 합니다.

```text
우리 가게: 커피한잔. 서울 동네 상권 20석 카페, 노트북 손님 많음.

아래 내용으로 손님 안내문을 3가지 버전으로 써 줘.
① 인쇄용 A4: 제목 + 5–8문장 + 마지막에 "커피한잔 드림"
② 인스타 스토리: 2–3줄, 해시태그 없이
③ 카톡 채널: 3–4문장, 인사 1문장 포함

공통 규칙:
- 존댓말. 과한 사과나 감탄사 금지.
- 날짜·시간·금액은 내가 준 것만 써. 지어내지 마.
- 손님이 궁금할 것(언제부터, 얼마나, 왜)을 빠뜨리지 마.
- 매장 규칙 안내는 추가로: "금지" "불가" 대신 "부탁드립니다" 톤. 규칙마다 이유를 짧게. 다른 손님을 위한 것임을 한 번 언급.

안내 종류: 매장 규칙
내용:
1인 1음료 부탁. 노트북 이용은 2시간까지, 이후 음료 추가 주문 시 연장 가능. 주말 12–15시는 콘센트 자리 이용 2시간 제한. 통화는 매장 밖에서.
```

**예상 결과:** "함께 쓰는 공간이라 부탁드립니다"로 시작해, 규칙 4개가 각각 1줄 이유와 함께 나옵니다.

**다듬는 법:**
- 너무 부드러워서 규칙이 안 보이면: "규칙은 굵은 글씨로 구분되게, 이유는 그 아래 작게."
- 규칙이 5개 넘으면 줄이세요. 손님은 3–4개까지만 기억합니다.

## 다음 순서

1. **지금 당장:** 이번 달에 붙일 공지 하나를 골라 위 틀로 만들어 출입문에 붙이세요.
2. **그다음:** 만든 A4 안내문을 "이 내용을 30초 안에 읽히게 더 줄여 줘"로 한 번 더 다듬어 보세요.
3. **나중에:** 디자인(글꼴, 색, 이미지)은 3교시 마케팅에서 다룹니다. 지금은 글만.

## 흔한 실수

1. **날짜·요일을 검증 안 한다.** AI는 달력을 모릅니다. 요일은 사장님이 폰 달력으로 확인하세요.
2. **가격 인상 안내에 사과가 5번 나온다.** 사과가 많을수록 손님은 불안해합니다. 이유 1문장, 사과 1번이면 충분합니다.
3. **A4 안내문을 카톡에 그대로 보낸다.** 카톡에서 8문장은 읽히지 않습니다. 반드시 3–4문장 버전을 따로 보내세요.

{{< callout type="warning" >}}
**무시해도 되는 것:** 공지문 디자인 툴(캔바, 미리캔버스) 사용법, 폰트 선택, 인쇄 용지 종류. 지금은 글만 완성하면 됩니다. 한글이나 워드에 붙여 넣고 글자 크기만 키워서 뽑아도 됩니다.
