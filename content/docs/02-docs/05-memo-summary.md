⏱ 소요 시간: 8분

✅ 이 페이지를 끝내면 할 수 있는 것
- 긴 카톡 대화, 통화 메모, 회의 내용을 붙여 넣고 "결정된 것 / 할 일 / 확인할 것"으로 받습니다.
- 음성 메모를 할 일 목록으로 바꿉니다.
- 계약서·공문을 3줄로 요약해 "뭘 물어봐야 하는지" 알아냅니다.
- 매출 엑셀 정리에 필요한 수식을 물어보고 붙여 넣습니다.

{{< callout type="error" >}}
카톡 대화, 통화 메모, 계약서에는 상대 이름·전화번호·계좌·주소가 섞여 있습니다. 붙여 넣기 전에 지우거나 "A", "거래처B"로 바꾸세요. 특히 직원 주민번호, 고객 카드번호는 절대 넣지 마세요. 요약에는 필요 없는 정보입니다.
{{< /callout >}}

## 먼저: 요약은 "형식"을 정해 주면 끝납니다

"요약해 줘"라고만 하면 줄글이 옵니다. 사장님에게 필요한 건 줄글이 아니라 **결정된 것 / 할 일 / 확인할 것** 세 칸입니다. 이 세 칸을 모든 요약 프롬프트에 넣습니다.

## 1. 긴 카톡·통화·회의 요약

{{% steps %}}

### 복붙 프롬프트

```text
아래는 [거래처와의 카톡 대화 / 통화 후 적은 메모 / 직원 회의 내용]이야. 3칸으로 정리해 줘.
1. 결정된 것 (누가, 무엇을, 언제까지)
2. 내가 할 일 (체크박스 목록)
3. 아직 확인 안 된 것 (질문 형태로)
- 대화에 없는 내용은 추가하지 마.
- 각 칸 5줄 이내.

내용:
[붙여넣기. 이름·번호는 지우고]
```

### 업종 예시 완성본 (카페 "커피한잔", 인테리어 업체와 카톡)

```text
아래는 거래처와의 카톡 대화야. 3칸으로 정리해 줘.
1. 결정된 것 (누가, 무엇을, 언제까지)
2. 내가 할 일 (체크박스 목록)
3. 아직 확인 안 된 것 (질문 형태로)
- 대화에 없는 내용은 추가하지 마.
- 각 칸 5줄 이내.

내용:
[업체] 사장님 안녕하세요 카운터 상판 샘플 3종 보내드렸습니다
[나] 네 받았어요. 2번이 제일 낫네요. 근데 두께가 얇아 보여서
[업체] 2번은 30mm고 40mm도 가능합니다. 단가는 조금 올라가요
[나] 40mm로 할게요. 시공은 언제 가능해요?
[업체] 다음 주 목요일 오전 가능합니다. 하루면 끝나요
[나] 그날 휴무 걸게요. 잔금은 시공 끝나고 드리면 되죠?
[업체] 네 시공 후 당일 정산이면 됩니다. 40mm 단가는 내일 다시 보내드릴게요
```

### 예상 결과

```
1. 결정된 것
- 상판 2번 디자인, 두께 40mm
- 시공: 다음 주 목요일 오전, 하루 소요
- 잔금: 시공 당일 정산

2. 내가 할 일
☐ 다음 주 목요일 휴무 공지
☐ 40mm 단가 회신 확인 (내일)
☐ 잔금 준비

3. 확인 안 된 것
- 40mm 단가는 정확히 얼마인가?
- 시공 시작 시각은 몇 시인가?
- 폐기물 처리는 포함인가?
```

### 다듬는 법

- "확인 안 된 것"에 AI가 대화에 없는 걸 넣기도 합니다(폐기물 처리 등). 도움이 되면 두고, 아니면 지우세요.
- 할 일에 날짜가 빠졌으면: "할 일마다 마감일을 붙여 줘. 대화에 없으면 '미정'으로."

{{% /steps %}}

## 2. 음성 메모 → 할 일 목록

운전 중, 마감 후 떠오른 생각을 폰 음성 메모로 녹음하셨을 겁니다. 스마트폰 음성 메모 앱의 "텍스트 변환" 기능(또는 ChatGPT 앱의 마이크 버튼)으로 글자로 바꾼 뒤 붙여 넣습니다.

```text
아래는 내가 혼잣말로 녹음한 메모를 글자로 바꾼 거야. 말이 두서없어.
- 할 일만 뽑아서 체크박스 목록으로.
- 비슷한 건 하나로 합쳐.
- "오늘 / 이번 주 / 나중에"로 나눠.
- 내가 안 한 말은 추가하지 마.

메모:
[변환된 텍스트 붙여넣기]
```

**업종 예시 완성본 (헬스장 "튼튼짐"):**

```text
아래는 내가 혼잣말로 녹음한 메모를 글자로 바꾼 거야. 말이 두서없어.
- 할 일만 뽑아서 체크박스 목록으로.
- 비슷한 건 하나로 합쳐.
- "오늘 / 이번 주 / 나중에"로 나눠.
- 내가 안 한 말은 추가하지 마.

메모:
어 그 러닝머신 3번 벨트 소리 나는 거 AS 불러야 되고 아 그리고 이번 달 만료 회원한테 문자 돌려야 되는데 그거 오늘 해야 되나 내일 해도 되나 암튼 이번 주 안에 하고 샤워실 수건 주문도 해야 되고 아 맞다 PT 선생님 스케줄 다음 주 거 아직 못 받았네 그거 오늘 물어봐야지 그리고 나중에 여름 이벤트 뭐 할지 생각해 봐야 되고
```

**예상 결과:** 오늘(PT 스케줄 확인), 이번 주(AS 접수, 만료 회원 문자, 수건 주문), 나중에(여름 이벤트 기획)로 나뉜 체크박스 5개.

**다듬는 법:** 이 목록을 그대로 폰 메모앱이나 캘린더에 붙이세요. 여기서 더 다듬을 게 없습니다.

## 3. 계약서·공문 3줄 요약

임대차 계약서, 프랜차이즈 계약서, 구청 공문, 플랫폼 약관 변경 안내. 다 읽기 전에 **뭘 조심해야 하는지**부터 압니다.

{{< callout type="error" >}}
AI의 계약서 요약은 **읽기 전 길잡이**입니다. 조항 해석, 불리한 조건 판단, 서명 여부는 반드시 변호사·법무사·세무사 등 전문가에게 확인하세요. AI는 계약서의 일부를 놓치거나 잘못 읽을 수 있고, 그 책임은 AI가 지지 않습니다. 세금·노무(근로계약, 4대보험) 관련 문서는 세무사·노무사 확인이 필수입니다.
{{< /callout >}}

```text
아래 [계약서 / 공문 / 약관 안내]를 읽고 정리해 줘.
1. 한 줄 요약: 이 문서가 나에게 요구하는 것
2. 돈·기한·의무: 내가 내야 할 것, 지켜야 할 날짜, 해야 할 일 (문서에 있는 것만)
3. 전문가에게 물어봐야 할 조항: 불리하거나 모호해 보이는 부분을 조항 번호와 함께
- 문서에 없는 내용은 추가하지 마.
- 해석이 확실하지 않으면 "불확실"이라고 표시해.

문서:
[붙여넣기. 이름·주소·계좌·주민번호는 지우고]
```

**업종 예시 완성본 (분식집 "행복분식", 배달 플랫폼 정책 변경 안내):**

```text
아래 약관 안내를 읽고 정리해 줘.
1. 한 줄 요약: 이 문서가 나에게 요구하는 것
2. 돈·기한·의무: 내가 내야 할 것, 지켜야 할 날짜, 해야 할 일 (문서에 있는 것만)
3. 전문가에게 물어봐야 할 조항: 불리하거나 모호해 보이는 부분을 조항 번호와 함께
- 문서에 없는 내용은 추가하지 마.
- 해석이 확실하지 않으면 "불확실"이라고 표시해.

문서:
[플랫폼에서 받은 정책 변경 안내 전문 붙여넣기]
```

**예상 결과:** "다음 달부터 수수료 체계가 바뀌며 [날짜]까지 동의하지 않으면 [결과]" 식의 한 줄, 그 아래 날짜·금액 목록, 마지막에 "제3조 2항 '별도 정하는 바' — 불확실" 같은 확인 항목.

**다듬는 법:**
- 문서가 길어 한 번에 안 들어가면 장(章)별로 나눠 넣고, 마지막에 "위 요약들을 하나로 합쳐 줘".
- 3번 항목을 들고 전문가에게 가세요. "이 계약서 봐 주세요"보다 "이 세 조항이 걱정돼요"가 상담 시간을 절반으로 줄입니다.

## 4. 엑셀 수식 물어보기 — 수식만 받아서 붙여넣기

엑셀·구글 시트에 매출을 정리하고 있다면, **수식을 외울 필요가 없습니다.** 표가 어떻게 생겼는지 알려 주고 수식만 받습니다.

원칙: 데이터를 붙여 넣지 말고 **열 이름과 예시 2줄**만 알려 주세요. 매출 전체를 AI에 넣을 필요가 없습니다.

{{% steps %}}

### 복붙 프롬프트

```text
[엑셀 / 구글 시트]를 쓰고 있어. 내 표는 이렇게 생겼어.
- A열: 날짜 (예: 2026-09-01)
- B열: 요일 (예: 월)
- C열: 매출 (예: 350000)
- 데이터는 2행부터 [마지막 행]까지.

원하는 것:
1. [무엇을 계산하고 싶은지]
2. [무엇을 계산하고 싶은지]

- 수식만 줘. 설명은 한 줄씩만.
- 어느 셀에 넣으면 되는지 같이 알려 줘.
- 수식은 한국어 엑셀 기준으로 (구분자 쉼표).
```

### 업종 예시 완성본 (카페 "커피한잔" 월 매출표)

```text
구글 시트를 쓰고 있어. 내 표는 이렇게 생겼어.
- A열: 날짜 (예: 2026-09-01)
- B열: 요일 (예: 월)
- C열: 매출 (예: 350000)
- 데이터는 2행부터 400행까지.

원하는 것:
1. 월별 매출 합계 (9월, 10월 각각)
2. 요일별 평균 매출 (월~일)
3. 매출이 가장 높았던 날짜

- 수식만 줘. 설명은 한 줄씩만.
- 어느 셀에 넣으면 되는지 같이 알려 줘.
- 수식은 한국어 엑셀 기준으로 (구분자 쉼표).
```

### 예상 결과

```
1. 9월 합계 → E2: =SUMIFS(C2:C400, A2:A400, ">=2026-09-01", A2:A400, "<=2026-09-30")
2. 월요일 평균 → F2: =AVERAGEIF(B2:B400, "월", C2:C400)   (화~일은 "월"만 바꿔서)
3. 최고 매출 날짜 → G2: =INDEX(A2:A400, MATCH(MAX(C2:C400), C2:C400, 0))
```

### 다듬는 법

- 수식을 붙였는데 `#VALUE!`나 `#N/A`가 뜨면, 그 오류 메시지와 수식을 그대로 붙여 넣고 "이 오류가 왜 나?"라고 물으세요. 대부분 날짜가 글자로 저장돼 있거나 열이 다른 경우입니다.
- 요일별 평균을 7개 셀에 한 번에: "월~일 7개 셀에 넣을 수식을 표로 줘."
- 결과가 이상하면 그 달 매출 2–3일치를 손으로 더해서 대조하세요. 수식 오류는 눈으로 잡는 게 제일 빠릅니다.

{{% /steps %}}

## 다음 순서

1. **지금 당장:** 폰에 있는 긴 카톡 대화 하나를 3칸 요약으로 돌려 보세요.
2. **그다음:** 매출표가 있으면 수식 프롬프트로 월별 합계를 받아 붙이세요.
3. **나중에:** 자동 요약(카톡 연동, 녹음 자동 변환)은 지금 필요 없습니다. 복사 → 붙여넣기면 충분합니다.

## 흔한 실수

1. **요약해 달라고만 한다.** 줄글이 옵니다. "결정된 것 / 할 일 / 확인할 것" 3칸을 반드시 지정하세요.
2. **계약서 요약을 읽고 "이제 알았다"고 서명한다.** 요약은 뭘 물어볼지 정하는 용도입니다. 서명 전에는 전문가 확인.
3. **매출 데이터 전체를 AI에 붙여 넣는다.** 필요 없습니다. 열 이름과 예시 2줄이면 수식이 나옵니다. 데이터는 사장님 컴퓨터에 두세요.

{{< callout type="warning" >}}
**무시해도 되는 것:** 엑셀 매크로, VBA, 피벗 테이블, 파일 업로드 분석 기능. 월별 합계와 요일별 평균은 수식 3개면 끝납니다. 더 복잡한 분석이 필요해지면 그때 배우면 됩니다.
