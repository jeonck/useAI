⏱ 소요 시간: 8분

✅ 이 페이지를 끝내면 할 수 있는 것
- 네이버·배민·쿠팡이츠·구글 리뷰 답글을 리뷰 유형별로 1분 안에 씁니다.
- 나쁜 리뷰에 감정 안 섞고 "공감 → 사실 → 조치 → 초대" 구조로 답합니다.
- 리뷰 10개를 한꺼번에 붙여 넣고 답글 10개를 한 번에 받습니다.

{{< callout type="error" >}}
리뷰에 고객 이름, 전화번호, 주문번호가 있으면 붙여 넣기 전에 지우세요. 닉네임은 괜찮습니다. 리뷰 본문만 넣어도 답글은 충분히 나옵니다.
{{< /callout >}}

## 먼저: 답글 규칙 3줄

ChatGPT에게 시키기 전에 사장님이 정할 것은 딱 3가지입니다.

1. **말투** — 존댓말 + 친근 / 존댓말 + 격식. 둘 중 하나.
2. **길이** — 배민·쿠팡이츠는 3–4문장, 네이버·구글은 4–6문장이면 충분합니다.
3. **절대 안 쓰는 말** — "죄송하지만 저희는~" 같은 변명 문장, 고객 탓하는 문장.

이 3줄을 컨텍스트 카드 아래에 붙여 두면 매번 안 써도 됩니다.

## 1. 좋은 리뷰 답글

가장 쉽고, 가장 많습니다. 여기서 손에 익히세요.

{{% steps %}}

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

아래 리뷰에 사장님 답글을 써 줘.
- 플랫폼: [네이버/배민/쿠팡이츠/구글]
- 말투: [존댓말, 친근하게]
- 길이: [3–4문장]
- 리뷰에서 언급한 메뉴나 상황을 한 번은 꼭 되짚어 줘.
- 답글 끝에 다음 방문을 자연스럽게 권해 줘.
- 이모지는 [1개만/쓰지 마].

리뷰:
[리뷰 내용 붙여넣기]
```

### 업종 예시 완성본 (동네 카페 "커피한잔")

```text
우리 가게: 커피한잔. 서울 동네 상권 20석 카페, 30–40대 직장인·주부 손님, 시그니처는 흑임자 라떼.

아래 리뷰에 사장님 답글을 써 줘.
- 플랫폼: 네이버
- 말투: 존댓말, 친근하게
- 길이: 3–4문장
- 리뷰에서 언급한 메뉴나 상황을 한 번은 꼭 되짚어 줘.
- 답글 끝에 다음 방문을 자연스럽게 권해 줘.
- 이모지는 1개만.

리뷰:
흑임자라떼 진짜 고소해요. 자리도 넓고 콘센트 많아서 노트북 하기 좋았어요. 다음에 또 올게요!
```

### 예상 결과

흑임자 라떼와 콘센트를 각각 한 번씩 언급하고, "다음엔 새로 나온 OO도 드셔 보세요" 식으로 끝나는 3–4문장 답글이 나옵니다.

실제로 ChatGPT(무료, 로그인 없이)에 넣었을 때 결과입니다.

![리뷰 답글 실제 결과](/images/chatgpt-review-demo.png)

### 다듬는 법

- 너무 길면: "2문장으로 줄여 줘."
- 너무 딱딱하면: "동네 사장님이 직접 쓴 것처럼 조금 더 편하게."
- 없는 메뉴를 추천하면: "우리 메뉴는 [목록]뿐이야. 이 안에서만 추천해."

{{% /steps %}}

## 2. 나쁜 리뷰 답글 — 사과 구조

나쁜 리뷰는 "누가 보는가"를 기억하세요. 리뷰 쓴 손님 한 명이 아니라, 앞으로 올 손님 100명이 읽습니다. 그래서 구조가 정해져 있습니다.

| 순서 | 내용 | 예 |
|---|---|---|
| 1. 공감 | 불편했던 감정을 먼저 인정 | "기다리신 시간이 길어 많이 불편하셨겠습니다." |
| 2. 사실 | 변명 말고 상황 설명 1문장 | "그날 점심 단체 주문이 겹쳐 조리가 늦어졌습니다." |
| 3. 조치 | 앞으로 무엇을 바꾸는지 | "단체 주문은 미리 준비해 대기 시간을 줄이겠습니다." |
| 4. 초대 | 다시 올 이유 | "다음에 오시면 제대로 대접하겠습니다." |

{{% steps %}}

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

아래는 우리 가게에 달린 불만 리뷰야. 사장님 답글을 써 줘.
- 순서: 공감 → 사실 설명 1문장 → 앞으로의 조치 → 다시 방문 권유
- 변명하지 마. 손님 탓하는 문장 절대 쓰지 마.
- "죄송합니다"는 1번만.
- 실제 상황: [사장님이 아는 사실을 1–2줄로]
- 앞으로 조치: [실제로 할 것]
- 길이: [4–5문장], 존댓말.

리뷰:
[리뷰 내용 붙여넣기]
```

### 업종 예시 완성본 (분식집 "행복분식")

```text
우리 가게: 행복분식. 학교 앞 분식집, 배민 주문 비중 60%, 점심 피크 12–1시.

아래는 우리 가게에 달린 불만 리뷰야. 사장님 답글을 써 줘.
- 순서: 공감 → 사실 설명 1문장 → 앞으로의 조치 → 다시 방문 권유
- 변명하지 마. 손님 탓하는 문장 절대 쓰지 마.
- "죄송합니다"는 1번만.
- 실제 상황: 점심 단체 주문 3건이 겹쳐서 배달이 25분 늦었음.
- 앞으로 조치: 피크 시간엔 배달 예상 시간을 앱에 미리 늘려서 표시하기로 함.
- 길이: 4–5문장, 존댓말.

리뷰:
떡볶이 다 불어서 왔어요. 40분 기다렸는데 이럴 거면 예상시간을 왜 20분이라고 해놓나요.
```

### 예상 결과

"불어 버린 떡볶이를 받으셨을 때 얼마나 실망하셨을지…"로 시작해, 단체 주문 사실 1문장, 예상 시간 표시 개선, 재방문 권유로 끝납니다.

### 다듬는 법

- 사과가 너무 납작 엎드리면: "사과는 유지하되 당당하게. 굽신거리는 표현 빼."
- 조치가 뜬구름이면: 사장님이 조치를 구체적으로 다시 써 주세요. AI는 사장님이 준 사실만 씁니다.
- 손님이 명백히 틀렸어도 답글에서 반박하지 마세요. "확인해 보니 [사실]이었습니다"까지만.

{{% /steps %}}

## 3. 악성 리뷰 답글 — 짧게, 사실만

욕설, 허위 사실, 경쟁 업체 의심 리뷰입니다. 여기서 길게 쓰면 집니다. 원칙은 **3문장, 사실만, 감정 0**.

{{% steps %}}

### 복붙 프롬프트

```text
아래 리뷰는 사실과 다르거나 악의적인 리뷰야. 답글을 써 줘.
- 3문장 이내. 감정 표현 금지. 반박 금지.
- 확인된 사실 1문장: [사장님이 확인한 사실]
- "확인이 필요하면 매장으로 연락 부탁드립니다" 문장 포함.
- 손님을 자극하는 단어("허위", "거짓") 쓰지 마.
- 존댓말, 차분하게.

리뷰:
[리뷰 내용 붙여넣기]
```

### 업종 예시 완성본 (네일샵 "미소네일")

```text
아래 리뷰는 사실과 다르거나 악의적인 리뷰야. 답글을 써 줘.
- 3문장 이내. 감정 표현 금지. 반박 금지.
- 확인된 사실 1문장: 해당 날짜에 그 시술 예약 기록이 없음.
- "확인이 필요하면 매장으로 연락 부탁드립니다" 문장 포함.
- 손님을 자극하는 단어("허위", "거짓") 쓰지 마.
- 존댓말, 차분하게.

리뷰:
젤 하고 이틀 만에 다 떨어짐. 돈 아까움. 절대 가지 마세요 다른 데 가세요.
```

### 예상 결과

"불편을 드려 죄송합니다. 말씀하신 날짜의 시술 기록을 확인하고 있습니다. 확인이 필요하시면 매장으로 연락 부탁드립니다." 수준의 3문장.

### 다듬는 법

- 이걸로 끝입니다. 더 다듬지 마세요. 악성 리뷰 답글은 짧을수록 좋습니다.
- 플랫폼 신고는 별도로 하세요. 답글과 신고는 다른 일입니다.

{{% /steps %}}

## 4. 리뷰 10개 한꺼번에 답글 받기

매일 하나씩 붙여 넣지 마세요. 저녁에 모아서 한 번에 합니다.

```text
[컨텍스트 카드 붙여넣기]

아래 리뷰 10개에 각각 답글을 써 줘.
- 번호를 붙여서 리뷰 순서대로.
- 좋은 리뷰: 3문장, 언급한 메뉴 되짚기, 재방문 권유.
- 불만 리뷰: 공감 → 사실 → 조치 → 초대 순서, 4–5문장, 죄송합니다 1번만.
- 답글끼리 첫 문장이 겹치지 않게.
- 존댓말, 친근하게, 이모지 없이.

리뷰 1: [내용]
리뷰 2: [내용]
...
리뷰 10: [내용]
```

**예상 결과:** 번호 붙은 답글 10개. 불만 리뷰에는 사장님이 사실·조치를 안 줬으니 "[조치 내용]" 식으로 빈칸이 남을 수 있습니다. 그 부분만 채워 넣으세요.

**다듬는 법:** "3번, 7번은 너무 길어. 절반으로." 처럼 번호로 지시하면 됩니다.

## 흔한 실수

1. **답글에서 손님과 싸운다.** 답글을 읽는 건 그 손님이 아니라 다음 손님입니다. 사실만 쓰고 끝내세요.
2. **AI가 지어낸 조치를 그대로 올린다.** "앞으로 매일 위생 점검을 하겠습니다"를 AI가 썼다고 진짜 하게 되는 게 아닙니다. 사장님이 실제로 할 것만 남기세요.
3. **모든 답글이 똑같은 문장으로 시작한다.** "소중한 리뷰 감사합니다"가 10개 연속이면 복붙 티가 납니다. "첫 문장 겹치지 않게"를 꼭 넣으세요.

{{< callout type="warning" >}}
**무시해도 되는 것:** "리뷰 답글이 검색 순위에 영향을 준다"는 이야기, 답글 최적 글자 수, 답글 작성 시간대. 지금은 신경 쓰지 마세요. 답글을 빠짐없이 다는 것 자체가 전부입니다.
{{< /callout >}}
