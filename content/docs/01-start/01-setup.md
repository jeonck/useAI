⏱ **소요 시간:** 10분

✅ **이 페이지를 끝내면 할 수 있는 것**
- 컴퓨터든 스마트폰이든 ChatGPT를 열어 질문을 던지고 답을 받습니다.
- 화면에서 딱 3군데만 알면 됩니다. 나머지는 무시합니다.

{{< callout type="info" >}}
무료 버전으로 이 사이트의 과정 전부 가능합니다. 유료 요금제는 공식 사이트에서 확인하세요. 지금은 결제하지 마세요.
{{< /callout >}}

## 무엇부터: 계정 만들기 (3분)

{{% steps %}}

### 1단계. 접속

- 컴퓨터: 브라우저에서 **chatgpt.com** 접속
- 스마트폰: 앱스토어(아이폰) 또는 플레이스토어(안드로이드)에서 **ChatGPT** 검색 → 설치. 제작사가 **OpenAI**인지 확인하세요. 비슷한 이름의 다른 앱이 많습니다.

### 2단계. 가입

"가입" 또는 "Sign up"을 누르고, 구글 계정이나 애플 계정으로 로그인하세요. 이메일로 새로 만드는 것보다 빠릅니다.

### 3단계. 로그인 확인

로그인이 되면 가운데에 큰 입력창이 보입니다. 여기까지 되면 끝입니다.

{{% /steps %}}

## 그다음: 화면에서 알아야 할 3군데 (2분)

![ChatGPT 첫 화면](/images/chatgpt-home.png)

| 위치 | 이름 | 하는 일 |
|---|---|---|
| 가운데 아래 | **입력창** | 여기에 질문을 씁니다. 엔터(또는 화살표 버튼)로 보냅니다. |
| 왼쪽 위 | **새 채팅** | 주제가 바뀌면 여기를 눌러 새로 시작합니다. |
| 왼쪽 목록 | **대화 목록** | 예전 대화가 자동 저장됩니다. 눌러서 이어서 할 수 있습니다. |

입력창 근처에 모델 이름을 고르는 메뉴가 보일 수 있습니다. 건드리지 마세요. 기본값 그대로 두면 됩니다.

## 그다음: 첫 질문 던지기 (3분)

아래 프롬프트를 그대로 복사해서 입력창에 붙여 넣고 엔터를 누르세요. [대괄호] 부분만 우리 가게로 바꾸면 됩니다.

**복붙 프롬프트**

```text
나는 [업종]을 운영하는 사장이야. 가게 이름은 [가게 이름]이야.
오늘 인스타그램에 올릴 짧은 인사글을 3줄로 써줘.
```

**완성 예시** (동네 카페 "커피한잔")

```text
나는 동네 카페를 운영하는 사장이야. 가게 이름은 커피한잔이야.
오늘 인스타그램에 올릴 짧은 인사글을 3줄로 써줘.
```

**예상 결과**

3줄짜리 인사글이 나옵니다. 조금 뻔한 내용이어도 괜찮습니다. 지금은 "질문하면 답이 온다"를 확인하는 단계입니다.

**다듬는 법**

답이 마음에 안 들면 같은 대화창에 이어서 쓰세요. 새 채팅을 열 필요 없습니다.

```text
더 짧게, 그리고 이모지 빼줘.
```

## 스마트폰이면: 음성 입력 (1분)

앱의 입력창 오른쪽에 마이크 모양 버튼이 있습니다. 누르고 말하면 글자로 바뀝니다. 타자가 느리면 이 방법이 훨씬 빠릅니다. 가게에서 손님 없을 때 한 손으로 쓰기 좋습니다.

## 안전 사용 3원칙

이 세 가지만 지키면 됩니다. 이후 모든 페이지에 적용됩니다.

1. **개인정보 입력 금지.** 손님 이름·전화번호·주소·카드번호, 직원 주민번호는 절대 넣지 마세요. "단골 손님 A" 처럼 바꿔서 쓰세요.
2. **사실은 확인.** AI는 그럴듯하게 틀린 말을 합니다. 가격, 법규, 날짜, 통계는 반드시 따로 확인하세요.
3. **최종 판단은 사장님.** AI는 초안을 만들어 주는 직원입니다. 결재는 사장님이 합니다.

{{< callout type="error" >}}
세무·노무·법률 관련 답변은 초안/참고용입니다. 최종 결정은 세무사·노무사·변호사에게 확인하세요.
{{< /callout >}}

## 흔한 실수

1. **결제부터 하기.** 무료로 충분합니다. 한 달 써보고 부족하면 그때 생각하세요.
2. **질문 하나 하고 새 채팅 열기.** 답이 아쉬우면 같은 창에서 "더 짧게"라고 이어 쓰세요. 대화가 쌓일수록 답이 좋아집니다.
3. **비슷한 이름의 다른 앱 설치.** 제작사가 OpenAI인지 확인하세요.

{{< callout type="warning" >}}
**무시해도 되는 것**
- AI가 어떻게 작동하는지, 원리
- 모델 이름과 버전 차이 (GPT-어쩌구 숫자들)
- 설정 메뉴 대부분. 이 과정에서는 딱 두 개(1교시 3장의 맞춤 설정, 마무리 4장의 데이터 제어)만 씁니다.
{{< /callout >}}
