⏱ **소요 시간:** 5분

✅ **이 페이지를 끝내면 할 수 있는 것**
- 아래 체크리스트를 메모앱에 복사하고, 오늘 첫 칸에 체크합니다.
- 막혔을 때 쓰는 "메타 프롬프트" 1개를 저장합니다. 이것만 있으면 배우지 않은 일도 시킬 수 있습니다.

## 왜 30일인가

습관은 "매일 조금"이 "가끔 많이"를 이깁니다. 하루 5분, 프롬프트 1개면 됩니다. 4주 뒤에는 생각 없이 ChatGPT를 엽니다.

주차별 목표는 이렇습니다.

| 주차 | 목표 | 하루 분량 |
|---|---|---|
| 1주차 | 매일 프롬프트 1개 | 5분 |
| 2주차 | 리뷰 답글 + SNS 루틴 고정 | 10분 |
| 3주차 | 문서(공지·안내문·표) 만들기 | 10분 |
| 4주차 | 운영(원가·체크리스트·직원) | 10분 |

## 무엇부터: 체크리스트 복사 (2분)

아래 전체를 복사해서 메모앱에 "30일 플랜"이라는 제목으로 저장하세요. 카카오톡 나에게 보내기도 됩니다. 한 일은 `[ ]` 를 `[x]` 로 바꾸거나 줄을 지우세요.

### 1주차 — 매일 프롬프트 1개 (라이브러리에서 꺼내 쓰기)

- [ ] 1일. 저장한 프롬프트 중 1개 골라 실제로 씀 (결과물을 진짜 게시·발송)
- [ ] 2일. 리뷰 답글 1개
- [ ] 3일. 인스타 캡션 1개
- [ ] 4일. 이번 주 공지 1개 (휴무·이벤트·근무표 중 아무거나)
- [ ] 5일. 긴 글 3줄 요약 1개 (뉴스, 공문, 거래처 메일 아무거나)
- [ ] 6일. 새 프롬프트 1개 만들어 라이브러리에 추가
- [ ] 7일. 쉬는 날. 이번 주 가장 잘 된 것 1개만 메모

### 2주차 — 리뷰·SNS 루틴 고정

- [ ] 8일. 지난주 리뷰 전부 답글 (한 대화에서 몰아서)
- [ ] 9일. 인스타 캡션 5버전 뽑고 1개 게시
- [ ] 10일. 해시태그 세트 1개 만들어 저장
- [ ] 11일. 카드뉴스 5장 문구 1세트
- [ ] 12일. 이번 주 리뷰 답글
- [ ] 13일. 다음 주 인스타 글 2개 미리 뽑아 두기
- [ ] 14일. 월요일 10분 루틴에 리뷰·SNS 2개 고정 (메모 수정)

### 3주차 — 문서

- [ ] 15일. 가격 인상 안내문 초안 (당장 안 올려도 만들어 두기)
- [ ] 16일. 예약 확인 문자 양식
- [ ] 17일. 미수금 정중 요청 문자 양식
- [ ] 18일. 메뉴판·안내문 영어(또는 필요한 언어) 번역
- [ ] 19일. 자주 받는 손님 질문 5개 → 답변 양식
- [ ] 20일. 세무사·노무사에게 물어볼 것 정리 (다음 상담 때 들고 가기)
- [ ] 21일. 3주차 결과물 전부 메모앱 "양식" 폴더에 저장

### 4주차 — 운영

- [ ] 22일. 대표 메뉴 3개 원가·마진 표
- [ ] 23일. 오픈·마감 체크리스트 (직원용으로 인쇄)
- [ ] 24일. 신입 직원 첫날 안내문
- [ ] 25일. 이번 달 매출 메모 → 잘 된 것·안 된 것 정리
- [ ] 26일. 다음 달 이벤트 아이디어 5개 → 1개 고르기
- [ ] 27일. 라이브러리 정리: 한 달 동안 안 쓴 프롬프트 삭제
- [ ] 28일. 월요일 10분 루틴 최종본 확정
- [ ] 29일. 이 사이트 치트시트 다시 인쇄 (내 프롬프트로 바꿔서)
- [ ] 30일. 다음 30일 목표 3줄 쓰기

## 그다음: 막힐 때 쓰는 메타 프롬프트 (2분)

체크리스트에 있는 일이든 없는 일이든, "이걸 AI한테 어떻게 시키지?"에서 막히면 이걸 쓰세요. AI에게 프롬프트를 대신 써 달라고 하는 프롬프트입니다. 메모앱 맨 위에 저장하세요.

**복붙 프롬프트**

```text
[컨텍스트 카드 붙여넣기]

---

지금 내가 하려는 일: [하려는 일을 한 문장으로]
이 일을 너에게 어떻게 시켜야 하는지 알려줘.
1. 내가 너에게 미리 알려줘야 할 정보 목록
2. 그 정보를 넣어서 바로 복붙할 수 있는 프롬프트 1개
3. 결과가 이상할 때 고치는 방법 2가지
```

**완성 예시** (동네 카페 "커피한잔")

```text
나는 동네 카페 "커피한잔" 사장이야. 서울 주택가 골목, 테이블 6개, 주 고객은 30–40대 동네 주민과 재택근무자.

---

지금 내가 하려는 일: 단골 손님 20명한테 겨울 신메뉴 출시 알림 문자를 보내고 싶어
이 일을 너에게 어떻게 시켜야 하는지 알려줘.
1. 내가 너에게 미리 알려줘야 할 정보 목록
2. 그 정보를 넣어서 바로 복붙할 수 있는 프롬프트 1개
3. 결과가 이상할 때 고치는 방법 2가지
```

**예상 결과**

"신메뉴 이름·가격·출시일·문자 길이 제한·쿠폰 유무를 알려 달라"는 목록과, 그걸 채우면 되는 프롬프트, 그리고 "너무 광고 같으면 이렇게 말하라"는 수정법이 나옵니다.

**다듬는 법**

목록의 정보를 채워서 바로 이어 쓰세요. 새 채팅 열 필요 없습니다.

```text
신메뉴는 [이름], [가격], [날짜] 출시. 문자는 80자 이내. 쿠폰 없음. 이제 문자 써줘.
```

## 이건 나중에

- 30일이 끝나면 라이브러리에서 실제로 쓴 프롬프트만 남기세요. 보통 8–12개가 남습니다. 그게 우리 가게 전용 도구입니다.
- 2개월차부터는 체크리스트 없이 월요일 10분 루틴만 유지하면 됩니다.

## 흔한 실수

1. **하루 빠지면 포기.** 빠진 날은 건너뛰고 다음 날 것을 하세요. 30일 연속이 목표가 아니라 30개 체크가 목표입니다.
2. **결과물을 안 씀.** 뽑기만 하고 게시·발송을 안 하면 습관이 안 됩니다. 1일차 규칙은 "진짜 씀"입니다.
3. **순서 바꾸기.** 3주차 문서부터 하고 싶어도 1주차부터. 1주차가 손에 익어야 나머지가 빠릅니다.
