⏱ **소요 시간:** 8분

✅ **이 페이지를 끝내면 할 수 있는 것**
- 우리 가게에서 매주 반복하는 글쓰기·계산·정리 작업 표가 하나 생깁니다.
- 그 작업마다 프롬프트가 1개씩 붙어 있고, 월요일 아침 10분에 몰아서 처리합니다.

## 왜 목록을 만드는가

ChatGPT를 안 쓰게 되는 두 번째 이유는 "쓸 일이 생각 안 나서"입니다. 사실 쓸 일은 매주 똑같이 옵니다. 리뷰 답글, 인스타 글, 이번 주 발주 정리, 직원 공지. 그걸 표로 뽑아 두면 생각할 필요가 없어집니다.

## 무엇부터: 반복 작업 표 뽑기 (3분)

혼자 떠올리지 말고 ChatGPT에게 물어보세요. 빠집니다.

**복붙 프롬프트**

```text
[컨텍스트 카드 붙여넣기]

---

우리 가게에서 매주 반복되는 "글쓰기·계산·정리" 작업을 표로 뽑아줘.
- 컬럼: 작업 이름 / 보통 언제 하는지 / 걸리는 시간 / AI가 대신 써줄 수 있는지(O·△·X)
- 사장이 직접 손으로 하는 일(청소, 조리, 접객)은 빼줘
- 최대 10개
표 아래에 "AI가 대신 써줄 수 있는 O 항목 중 시간이 가장 많이 걸리는 3개"를 골라줘.
```

**완성 예시** (동네 카페 "커피한잔")

```text
나는 동네 카페 "커피한잔" 사장이야. 서울 주택가 골목, 테이블 6개, 주 고객은 30–40대 동네 주민과 재택근무자. 직원 1명(오후 파트). 인스타그램 운영 중, 네이버 플레이스 리뷰 있음.

---

우리 가게에서 매주 반복되는 "글쓰기·계산·정리" 작업을 표로 뽑아줘.
- 컬럼: 작업 이름 / 보통 언제 하는지 / 걸리는 시간 / AI가 대신 써줄 수 있는지(O·△·X)
- 사장이 직접 손으로 하는 일(청소, 조리, 접객)은 빼줘
- 최대 10개
표 아래에 "AI가 대신 써줄 수 있는 O 항목 중 시간이 가장 많이 걸리는 3개"를 골라줘.
```

**예상 결과**

이런 식의 표가 나옵니다. (내용은 가게마다 다릅니다)

| 작업 | 언제 | 시간 | AI |
|---|---|---|---|
| 네이버 리뷰 답글 | 매일 마감 후 | 15분 | O |
| 인스타 게시글 2개 | 화·금 | 30분 | O |
| 주간 발주 목록 정리 | 일요일 | 20분 | △ |
| 직원 근무표 공지 | 일요일 | 10분 | O |
| 주간 매출 정리 | 일요일 | 20분 | △ |

**다듬는 법**

표에 없는 일이 있으면 이어서 쓰세요.

```text
"단골 손님 생일 쿠폰 문자"도 매주 있어. 표에 추가하고 다시 3개 골라줘.
```

## 그다음: 작업마다 프롬프트 1개씩 붙이기 (3분)

표에서 O 항목 3–5개를 골라, 각각에 프롬프트를 1개씩 붙입니다. 직접 쓰지 말고 ChatGPT에게 만들어 달라고 하세요.

**복붙 프롬프트**

```text
위 표에서 O 항목 각각에 대해, 내가 매주 복붙해서 쓸 프롬프트를 1개씩 만들어줘.
- 매주 바뀌는 부분(날짜, 메뉴, 리뷰 내용 등)은 [대괄호]로
- 각 프롬프트는 5줄 이내
- 결과물 형식(문장 수, 톤, 이모지 여부)을 프롬프트 안에 명시
```

**완성 예시** (동네 카페 "커피한잔")

```text
위 표에서 O 항목 각각에 대해, 내가 매주 복붙해서 쓸 프롬프트를 1개씩 만들어줘.
- 매주 바뀌는 부분(날짜, 메뉴, 리뷰 내용 등)은 [대괄호]로
- 각 프롬프트는 5줄 이내
- 결과물 형식(문장 수, 톤, 이모지 여부)을 프롬프트 안에 명시
카페 톤: 친근하고 짧게, 존댓말, 이모지는 1개까지.
```

**예상 결과**

작업별 프롬프트 3–5개가 나옵니다. 이걸 앞 페이지 규칙대로 메모앱에 "컨텍스트 카드 + 프롬프트" 세트로 저장하세요. 이러면 라이브러리가 8–10개가 됩니다.

**다듬는 법**

마음에 안 드는 프롬프트 하나만 골라 고치세요.

```text
2번 프롬프트는 결과가 너무 광고 같아. "동네 사장이 직접 쓴 느낌"이 나게 프롬프트를 고쳐줘.
```

## 그다음: 월요일 아침 10분 루틴 만들기 (1분)

표와 프롬프트가 있으면 루틴은 자동으로 나옵니다. 메모앱에 이렇게 하나 더 저장하세요.

**완성 예시** (메모 제목: 월요일 10분)

```text
월요일 오픈 전 10분

1. ChatGPT 열기 → "[가게] 주간 루틴" 대화 열기 (없으면 새 채팅 + 컨텍스트 카드)
2. 인스타 이번 주 글 2개 → 프롬프트 "인스타 - 주간" 복붙 (3분)
3. 지난주 리뷰 답글 → 프롬프트 "리뷰답글" 복붙, 리뷰 붙여넣기 (3분)
4. 이번 주 직원 공지 → 프롬프트 "공지 - 근무표" 복붙 (2분)
5. 결과물 카톡 나에게 보내기 → 가게에서 꺼내 씀 (2분)
```

핵심은 **요일과 시간을 고정**하는 것입니다. "시간 날 때"는 안 옵니다. 월요일이 휴무면 화요일로 바꾸세요.

## 이건 나중에: ChatGPT 프로젝트(폴더)로 가게 자료 모아두기

ChatGPT에는 대화를 폴더처럼 묶는 "프로젝트" 기능이 있습니다. 왼쪽 메뉴에서 "프로젝트" 또는 "새 프로젝트"를 누르면 만들 수 있습니다.

쓸 만한 이유는 하나입니다. **프로젝트 안에 파일과 지시문을 넣어 두면, 그 안의 모든 대화가 자동으로 그걸 참고합니다.** 컨텍스트 카드를 매번 붙일 필요가 없어집니다.

- 프로젝트 이름: `커피한잔 가게 운영`
- 넣어 둘 것: 컨텍스트 카드(지시문에), 메뉴판 사진, 가격표, 자주 쓰는 공지 양식
- 그 안에서 "주간 루틴" 대화를 만들면 끝

{{< callout type="info" >}}
프로젝트 기능은 요금제나 시기에 따라 메뉴 위치와 이름이 다를 수 있습니다. 안 보이면 지금은 건너뛰고 컨텍스트 카드 복붙으로 하세요. 그것만으로 충분합니다.
{{< /callout >}}

## 흔한 실수

1. **표를 만들고 프롬프트를 안 붙임.** 표만 있으면 월요일에 다시 "뭐라고 시키지?"가 됩니다. 반드시 1:1로.
2. **루틴에 5개 이상 넣기.** 10분 넘어가면 안 합니다. 3–4개로.
3. **△·X 항목까지 AI로 하려고 함.** 매출 계산처럼 숫자를 넘겨야 하는 일은 4교시 원가 계산 방식으로 따로. 루틴엔 O만.

**무시해도 되는 것:** 자동화 도구(재피어, 메이크 등), 예약 발행 프로그램, ChatGPT 작업 예약 기능, API 연동. 월요일 10분에 손으로 복붙하는 게 사장님한테는 더 빠르고 안전합니다.
