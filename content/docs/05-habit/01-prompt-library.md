⏱ **소요 시간:** 8분

✅ **이 페이지를 끝내면 할 수 있는 것**
- 오늘 잘 된 프롬프트 5개가 메모앱에 저장되어 있습니다. 다음 주에 열어서 복붙만 하면 됩니다.
- ChatGPT 대화 목록에서 "가게용 대화"를 3초 안에 찾습니다.

## 왜 저장하는가

ChatGPT는 대화를 자동 저장합니다. 그런데 일주일 뒤에 "그때 리뷰 답글 잘 나왔던 대화"를 찾으려면 목록을 한참 뒤져야 합니다. 그래서 다시 안 열게 됩니다.

해결은 단순합니다. **잘 된 프롬프트를 메모앱에 따로 저장**합니다. ChatGPT 안이 아니라 메모앱에. 메모앱은 가게에서 스마트폰으로 바로 열리기 때문입니다.

## 무엇부터: 메모앱 고르기 (1분)

이미 쓰는 것 하나만 쓰세요. 새로 깔지 마세요.

| 스마트폰 | 메모앱 | 장점 |
|---|---|---|
| 아이폰 | 기본 **메모** 앱 | 폴더 만들기 쉬움. 맥과 자동 동기화. |
| 삼성 | **삼성 노트** | 폴더 만들기 쉬움. |
| 둘 다 | **카카오톡** "나에게 보내기" | 컴퓨터 카톡과 바로 동기화. 검색 잘 됨. 폴더는 없음. |

카카오톡을 고르면 메시지 앞에 `#프롬프트` 를 붙여 두세요. 나중에 검색창에 `#프롬프트` 만 치면 다 나옵니다.

## 그다음: 오늘 쓴 프롬프트 5개 고르기 (3분)

오늘 ChatGPT 대화 목록을 위에서부터 훑으세요. 답이 마음에 들어서 실제로 썼거나 쓸 것 같은 대화만 고릅니다. 5개면 충분합니다.

어떤 걸 골라야 할지 모르겠으면 ChatGPT에게 물어보세요. 오늘 대화 중 하나를 열고 이렇게 쓰면 됩니다.

**복붙 프롬프트**

```text
이 대화에서 내가 너에게 시킨 요청 중, 다음 주에도 똑같이 다시 쓸 만한 요청을 골라줘.
[업종] 사장 입장에서 매주 반복될 것 같은 것만.
각 요청을 "다음에 복붙해서 쓸 수 있는 형태"로 다시 정리해줘.
가게 이름·날짜·숫자처럼 바뀌는 부분은 [대괄호]로 바꿔줘.
```

**완성 예시** (동네 카페 "커피한잔")

```text
이 대화에서 내가 너에게 시킨 요청 중, 다음 주에도 똑같이 다시 쓸 만한 요청을 골라줘.
동네 카페 사장 입장에서 매주 반복될 것 같은 것만.
각 요청을 "다음에 복붙해서 쓸 수 있는 형태"로 다시 정리해줘.
가게 이름·날짜·숫자처럼 바뀌는 부분은 [대괄호]로 바꿔줘.
```

**예상 결과**

오늘 대화에서 뽑은 프롬프트 2–4개가 [대괄호] 형태로 정리되어 나옵니다. 이걸 그대로 메모앱에 붙이면 됩니다.

**다듬는 법**

너무 길게 정리해 주면 이어서 쓰세요.

```text
각 프롬프트를 5줄 이내로 줄여줘. 설명은 빼고 프롬프트만.
```

## 그다음: "컨텍스트 카드 + 프롬프트" 세트로 저장 (3분)

프롬프트만 저장하면 다음에 붙여 넣었을 때 "우리 가게 맞춤 답"이 안 나옵니다. 1교시에서 만든 **컨텍스트 카드를 항상 맨 위에** 붙여서 한 세트로 저장하세요.

{{% steps %}}

### 1단계. 메모 하나에 한 프롬프트

메모 1개 = 프롬프트 1개입니다. 한 메모에 5개를 다 넣으면 복사할 때 불편합니다.

### 2단계. 제목 규칙

제목은 "**용도 - 상황**" 으로 씁니다. 예:

- `리뷰답글 - 별점 나쁠 때`
- `인스타 - 신메뉴 소개`
- `문자 - 예약 확인`
- `공지 - 임시 휴무`
- `정리 - 세무사한테 물어볼 것`

이 규칙이면 메모 검색창에 "리뷰"만 쳐도 나옵니다.

### 3단계. 본문 구조

본문은 아래 순서로 붙입니다. 이 구조 그대로 복사해서 ChatGPT에 넣으면 바로 답이 나옵니다.

```text
[여기에 1교시 컨텍스트 카드 전체를 붙여넣기]

---

[여기에 프롬프트 붙여넣기]
```

**완성 예시** (동네 카페 "커피한잔", 메모 제목: 리뷰답글 - 별점 나쁠 때)

```text
나는 동네 카페 "커피한잔" 사장이야. 서울 주택가 골목, 테이블 6개, 주 고객은 30–40대 동네 주민과 재택근무자. 톤은 친근하고 짧게, 존댓말.

---

아래 리뷰에 사장이 직접 쓴 것처럼 답글을 써줘.
- 3–4문장, 변명하지 말고 먼저 사과
- 어떤 점을 고칠지 1가지 구체적으로
- 마지막에 다시 와달라는 말 한 줄
리뷰: [리뷰 내용 붙여넣기]
```

## 그다음: ChatGPT 대화 제목 바꾸기·고정 (1분)

메모앱에 저장했어도, ChatGPT 안에서 이어서 하고 싶은 대화가 있습니다. 예를 들어 "이번 달 인스타 글" 대화는 매주 같은 대화에서 이어 쓰는 게 편합니다.

- **제목 바꾸기:** 왼쪽 대화 목록에서 그 대화에 마우스를 올리거나(컴퓨터) 길게 누르면(스마트폰) 메뉴가 뜹니다. "이름 바꾸기"를 눌러 `[가게] 인스타 9월` 처럼 바꾸세요. 자동 생성된 제목은 나중에 못 찾습니다.
- **고정:** 같은 메뉴에 "고정" 또는 비슷한 항목이 있으면 누르세요. 목록 맨 위에 붙습니다. 없으면 제목 앞에 `★` 을 붙이는 것으로 충분합니다.

## 이건 나중에: 일주일에 하나씩 추가

오늘 5개면 끝입니다. 이후에는 **일주일에 1개만** 추가하세요. 그 주에 ChatGPT로 뭔가 잘 됐을 때 "이거 다음에도 쓰겠다" 싶으면 그때 저장합니다. 한 달이면 9개, 석 달이면 17개입니다. 그 정도면 가게 업무 대부분이 덮입니다.

## 흔한 실수

1. **컨텍스트 카드 없이 프롬프트만 저장.** 다음에 붙이면 "일반적인 카페" 답이 나옵니다. 반드시 세트로.
2. **ChatGPT 대화 목록만 믿기.** 대화가 수십 개 쌓이면 못 찾습니다. 메모앱이 본진입니다.
3. **처음부터 20개 저장.** 안 씁니다. 5개로 시작하고 진짜 쓴 것만 남기세요.
