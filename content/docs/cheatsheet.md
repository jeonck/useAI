**인쇄해서 카운터 옆에 붙여두세요.** 이 사이트 4시간이 이 한 장에 들어 있습니다.

**사용법 3줄**
1. 프롬프트 1번(컨텍스트 카드)을 먼저 붙이고, 그 아래에 필요한 번호를 붙입니다.
2. [대괄호]만 우리 가게 내용으로 바꿉니다. 나머지는 그대로.
3. 결과가 마음에 안 들면 새 채팅 열지 말고 같은 대화에 "더 짧게", "존댓말로", "이모지 빼줘"라고 이어 씁니다.

---

## 1. 컨텍스트 카드 헤더

모든 프롬프트 맨 위에 붙입니다. 한 번 만들어 메모앱에 저장.

```text
나는 [업종] "[가게 이름]" 사장이야.
위치: [동네·상권], 규모: [테이블 수 / 직원 수 / 월 주문 수 등]
주 고객: [연령대·특징]
우리 가게 특징: [1–2줄]
글 톤: [친근하고 짧게 / 정중하고 격식 있게], 존댓말, 이모지 [없음 / 1개까지]
---
```

## 2. 리뷰 답글 (좋은 리뷰 / 나쁜 리뷰)

별점 좋을 때, 나쁠 때 모두. 리뷰만 바꿔 넣습니다.

```text
아래 리뷰에 사장이 직접 쓴 것처럼 답글을 써줘.
- 좋은 리뷰면: 3문장, 구체적으로 어떤 점이 좋았다는지 언급하며 감사, 다음 방문 유도
- 나쁜 리뷰면: 4문장, 변명 없이 먼저 사과, 고칠 점 1가지 구체적으로, 다시 와달라는 말
- 손님 이름은 부르지 말 것
리뷰: [리뷰 내용 붙여넣기]
```

## 3. 휴무 공지

임시 휴무, 정기 휴무 변경, 명절 휴무.

```text
[날짜]부터 [날짜]까지 [사유: 명절 / 내부 공사 / 개인 사정] 휴무 공지를 써줘.
- 인스타용(3줄, 이모지 1개), 매장 출입문 부착용(2줄, 큰 글씨용) 두 가지
- 재오픈 날짜와 시간 명시
- 사과보다는 안내 톤으로
```

## 4. 가격 인상 안내

원재료 상승 등으로 가격 올릴 때.

```text
[날짜]부터 [메뉴/서비스명] 가격을 [기존 가격]에서 [변경 가격]으로 올리는 안내문을 써줘.
- 이유: [원재료 가격 상승 / 임대료 / 인건비] — 한 줄만, 구구절절 설명 금지
- 손님에게 감사와 양해를 구하되 미안해하는 톤은 아니게
- 매장 부착용 5줄, 인스타용 3줄 두 가지
```

## 5. 예약 확인 문자

예약 받은 뒤 보내는 확인 문자.

```text
예약 확인 문자를 써줘. 80자 이내, 존댓말.
포함: 가게 이름, [날짜 요일 시간], [인원/서비스명], 변경·취소는 [연락처]로
마지막에 "기다리겠습니다" 한 줄. 이모지 없음.
```

## 6. 미수금 정중 요청

거래처나 단체 손님에게 미입금 안내.

```text
[상대: 거래처 / 단체 예약 손님]에게 미입금 안내 문자를 써줘.
- 금액 [금액], 원래 입금일 [날짜], 항목 [내용]
- 정중하지만 명확하게. "혹시 착오가 있었는지" 톤으로 시작
- 입금 계좌는 [계좌 정보 — 문자 보낼 때 직접 입력]으로 표시만
- 5문장 이내
```

## 7. 인스타 캡션 5버전

같은 내용을 5가지 스타일로.

```text
[주제: 신메뉴 / 이벤트 / 일상] 인스타 캡션을 5가지 버전으로 써줘.
1) 한 줄 짧게  2) 질문으로 시작  3) 스토리텔링 4줄  4) 정보 위주(가격·기간)  5) 유머
각 버전 끝에 행동 유도 한 줄. 이모지는 버전당 1개. 해시태그는 빼고.
내용: [메뉴 이름, 가격, 기간, 특징]
```

## 8. 해시태그

캡션 뽑은 뒤 이어서.

```text
위 글에 붙일 해시태그 15개를 만들어줘.
- 지역 태그 5개([동네·역·상권 이름] 조합), 업종 태그 5개, 메뉴·상황 태그 5개
- 너무 큰 태그(#맛집, #카페)는 2개 이하
- 한 줄로 복사하기 쉽게 붙여서
```

## 9. 카드뉴스 5장 문구

인스타 카드뉴스 슬라이드별 문구.

```text
[주제]로 카드뉴스 5장 문구를 써줘.
- 1장: 제목(10자 이내) + 부제 한 줄
- 2–4장: 각 장 제목 1줄 + 본문 2줄 이내
- 5장: 마무리 + 행동 유도(방문 / 저장 / 예약)
- 각 장은 스마트폰 화면에서 3초 안에 읽히는 분량
내용: [핵심 내용 3–5줄]
```

## 10. 원가·마진 표

메뉴별 원가와 마진 계산. 숫자는 반드시 계산기로 재확인.

```text
아래 메뉴의 원가·마진 표를 만들어줘.
- 컬럼: 메뉴 / 판매가 / 재료비 / 재료비율(%) / 마진(원) / 마진율(%)
- 판매가는 부가세 [포함 / 별도]
- 표 아래에 마진율 낮은 순 3개와 각각 한 줄 개선 아이디어
메뉴: [메뉴명, 판매가, 재료비 — 한 줄에 하나씩]
```

## 11. 오픈·마감 체크리스트

직원용 인쇄 체크리스트.

```text
[업종] 매장의 오픈·마감 체크리스트를 만들어줘.
- 오픈 10개 이내, 마감 10개 이내, 순서대로
- 각 항목은 동사로 시작, 한 줄, 체크박스 □ 포함
- 우리 가게 특수 항목: [예: 원두 그라인더 청소, 온수기 전원, 간판 조명]
- A4 한 장에 인쇄할 수 있게
```

## 12. 메뉴판 번역

외국인 손님용.

```text
아래 메뉴를 [영어 / 일본어 / 중국어]로 번역해줘.
- 메뉴명 옆에 3–7단어 짧은 설명 추가 (외국인이 뭔지 알 수 있게)
- 고유 메뉴명은 소리 나는 대로 + 설명 (예: Tteokbokki — spicy rice cakes)
- 표 형식: 한글 / 번역 / 설명 / 가격
메뉴: [메뉴명과 가격 — 한 줄에 하나씩]
```

## 13. 긴 글 3줄 요약

공문, 거래처 메일, 지원사업 안내, 뉴스.

```text
아래 글을 3줄로 요약해줘.
1줄: 무슨 내용인지  2줄: 내가 해야 할 것(있으면)  3줄: 마감일·금액 등 숫자
숫자와 날짜는 원문 그대로. 없으면 "없음"이라고 써.
글: [붙여넣기]
```

## 14. 세무사 질문 정리

상담 전에 물어볼 것 정리. 답은 세무사에게.

```text
[상황: 예 — 직원 1명 추가 채용 / 배달앱 매출 증가 / 사업장 이전]에 대해
세무사(또는 노무사)에게 물어볼 질문을 정리해줘.
- 질문 5개 이내, 중요한 순서로
- 각 질문에 "내가 미리 준비해 갈 자료" 한 줄
- 답은 하지 마. 질문만.
```

## 15. 메타 프롬프트 — 막힐 때

"이걸 AI한테 어떻게 시키지?"에서 막히면.

```text
지금 내가 하려는 일: [한 문장으로]
이 일을 너에게 어떻게 시켜야 하는지 알려줘.
1. 내가 미리 알려줘야 할 정보 목록
2. 그 정보를 넣어서 바로 복붙할 수 있는 프롬프트 1개
3. 결과가 이상할 때 고치는 방법 2가지
```
