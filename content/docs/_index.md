그래서 이 과정에는 **설명만 듣는 시간이 없습니다.** 모든 페이지가 "복붙 프롬프트 → 결과 → 다듬기"입니다.

{{< callout type="info" >}}
**준비물** — 스마트폰 또는 PC, ChatGPT 무료 계정(1교시에서 만듭니다), 메모앱. 그게 전부입니다. 유료 결제 필요 없습니다.

## 무엇부터 배워야 하는가

순서가 중요합니다. 아래 순서를 바꾸지 마세요.

{{% steps %}}

### 1. 내 가게 컨텍스트 카드 (15분)

가게 이름·업종·주 고객·대표 상품·말투를 10줄로 정리해 메모앱에 저장하고, 모든 대화 첫 줄에 붙여넣습니다.
이 한 번의 연습이 **몇 달째 배우는 사람의 70%보다 앞서게** 만듭니다. 대부분은 이걸 안 하고 매번 "우리 가게는요…"부터 다시 설명하다가 지쳐서 그만둡니다.
→ [1교시 3장](01-start/03-context-card)

### 2. 프롬프트 4줄 공식 (15분)

역할 · 상황 · 요청 · 형식. 이 네 줄만 지키면 결과가 달라집니다. 외울 것은 이것뿐입니다.
→ [1교시 2장](01-start/02-prompt-formula)

### 3. 리뷰 답글 (8분)

가장 자주 하고, 가장 빨리 효과를 보는 일. 오늘 밀린 리뷰 10개를 한꺼번에 붙여넣고 답글 10개를 받아보세요. 여기서 "아, 되네"가 옵니다.
→ [2교시 1장](02-docs/01-review-reply)

### 4. 나머지는 필요할 때 펼쳐 보는 것

공지문, 캡션, 원가 계산, 직원 매뉴얼은 **지금 당장 필요한 것만** 하세요. 전부 순서대로 볼 필요 없습니다. 각 페이지는 독립적입니다.

{{% /steps %}}

## 완전히 무시해도 되는 것

{{< callout type="warning" >}}
아래는 4시간 안에 **단 1분도 쓰지 마세요.** 나중에 궁금해지면 그때 봐도 늦지 않습니다.

- AI가 어떻게 동작하는지 (원리, 학습, 토큰, 파라미터)
- 모델 이름·버전 차이 (GPT-몇, o-몇, 다른 회사 모델 비교)
- 프롬프트 엔지니어링 "기법" 이름들 (Chain-of-Thought, Few-shot 같은 용어)
- 설정 메뉴의 90% (필요한 두 개만 다룹니다 — 1교시 3장, 마무리 4장)
- 유료 결제 여부 고민 (이 과정 전부 무료 버전으로 됩니다)
- 유튜브 "AI로 월 천만 원" 류의 콘텐츠
- 여러 AI 도구를 동시에 써보기 (하나만 제대로. 이 과정은 ChatGPT 기준입니다)
{{< /callout >}}

## 절대 하지 말아야 할 것 3가지

{{< callout type="error" >}}
1. **고객·직원 개인정보를 입력하지 마세요.** 이름, 전화번호, 주소, 카드번호, 주민번호. 리뷰나 문자를 붙여넣기 전에 지우세요.
2. **세무·노무·법률 답변을 그대로 제출하지 마세요.** AI 답변은 초안입니다. 최종은 세무사·노무사·변호사가 확인합니다.
3. **숫자·날짜·법 조항은 반드시 확인하세요.** AI는 그럴듯하게 틀립니다. 출처를 물어보고, 공식 사이트에서 한 번 더 확인합니다.
{{< /callout >}}
