⏱ 소요 시간: 10분

✅ **이 페이지를 끝내면 할 수 있는 것**
- "표지 → 문제 → 해결 → 증거 → 행동" 5장 구조로 카드뉴스 문구를 한 번에 받습니다.
- Canva 무료 템플릿에 문구만 바꿔 넣어 오늘 인스타에 올립니다.

## 카드뉴스는 문구가 90%입니다

카드뉴스는 "디자인을 잘해야" 하는 게 아니라 "5장이 한 이야기로 이어지는지"가 전부입니다. 5장 공식은 이겁니다.

| 장 | 역할 | 글자 수 기준 |
|---|---|---|
| 1 표지 | 넘기게 만드는 한 줄 | 제목 12자 이내 + 부제 20자 이내 |
| 2 문제 | 손님이 겪는 불편·고민 | 2문장 |
| 3 해결 | 우리 가게가 그걸 어떻게 해결하는지 | 2–3문장 |
| 4 증거 | 사진·후기·숫자(실제 것만) | 1–2문장 |
| 5 행동 | 뭘 하면 되는지 (예약·방문·DM) | 1문장 + 연락 방법 |

문구는 AI가 쓰고, 사장님은 Canva에서 템플릿 골라 붙여 넣기만 합니다.

## 무엇부터: 5장 문구 받기

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

인스타그램 카드뉴스 5장 문구를 써 줘.
주제: [주제]
목적: [예: 신메뉴 알리기 / 신규 손님 유입 / 우리 가게 차별점 알리기]

구조:
1장 표지 — 제목 12자 이내, 부제 20자 이내
2장 문제 — 손님이 겪는 고민 2문장
3장 해결 — 우리가 어떻게 해결하는지 2–3문장
4장 증거 — [실제 후기·사실 붙여넣기] 를 근거로 1–2문장. 없는 사실 지어내지 말 것
5장 행동 — 뭘 하면 되는지 1문장 + [연락 방법]

각 장은 "N장 / 제목 / 본문" 형식으로. 카드 안에 들어갈 글이니 짧게.
마지막에 게시글 캡션 3줄과 해시태그 10개도 따로.
```

### 업종 예시 완성본 (동네 카페 "커피한잔")

```text
[컨텍스트 카드: 동네 카페 "커피한잔", 30대 직장인·주부 손님, 친근한 존댓말, 시그니처 흑임자라떼]

인스타그램 카드뉴스 5장 문구를 써 줘.
주제: 가을 신메뉴 5가지
목적: 신메뉴 알리고 이번 주 방문 유도

구조:
1장 표지 — 제목 12자 이내, 부제 20자 이내
2장 문제 — 손님이 겪는 고민 2문장
3장 해결 — 우리가 어떻게 해결하는지 2–3문장
4장 증거 — 아래 실제 후기를 근거로 1–2문장. 없는 사실 지어내지 말 것
   후기: "흑임자라떼 진짜 고소해요. 달지 않아서 좋았어요." / "소금빵이랑 같이 먹으니 딱이네요"
5장 행동 — 뭘 하면 되는지 1문장 + "매장 방문, 인스타 DM 문의"

신메뉴 5가지: 밤라떼, 단호박 크림 라떼, 무화과 타르트, 고구마 소금빵, 애플 시나몬 티
각 장은 "N장 / 제목 / 본문" 형식으로. 카드 안에 들어갈 글이니 짧게.
마지막에 게시글 캡션 3줄과 해시태그 10개도 따로.
```

### 예상 결과

```text
1장 / 가을이 왔어요 / 커피한잔 신메뉴 5가지
2장 / 아직도 아이스 아메리카노? / 아침저녁 쌀쌀한데 마실 게 마땅치 않죠. ...
3장 / 따뜻한 가을 라인업 / 밤라떼, 단호박 크림 라떼, ... 달지 않게 만들었어요.
4장 / 먼저 드셔 본 분들은 / "달지 않아서 좋았어요" — 흑임자라떼처럼 이번 가을 메뉴도 단맛을 줄였습니다.
5장 / 이번 주에 오세요 / 매장에서 바로 주문. 궁금한 건 DM으로.
```

여기에 캡션과 해시태그가 붙어 나옵니다.

### 다듬는 법

- 표지가 밋밋하면: "1장 제목 후보 5개 더. 질문형 2개, 숫자형 2개, 짧은 감탄형 1개."
- 신메뉴가 5개인데 3장에 다 못 넣으면: "3장을 3-1, 3-2로 나눠서 메뉴 5개를 2장에 배분해 줘. 총 6장." (카드뉴스는 5–7장이면 됩니다.)
- 4장에 쓸 후기가 없으면: 4장을 "메뉴 사진 크게" 장으로 바꾸세요. "4장은 사진 위에 얹을 한 줄 문구만 써 줘."

{{< callout type="error" >}}
4장 "증거"에 없는 후기·숫자를 넣지 마세요. AI에게 후기를 안 주면 그럴듯한 후기를 지어냅니다. 실제 후기가 없으면 사진으로 대체하세요.
{{< /callout >}}

## 그다음: Canva에서 5분 만에 제작

Canva 무료 계정이면 됩니다. 앱(스마트폰)에서도 똑같이 됩니다.

{{% steps %}}

### 1단계 — 템플릿 검색

Canva 검색창에 "**인스타그램 카드뉴스**" 또는 "**카드뉴스 5장**" 입력. 무료 표시 템플릿 중 글자 자리가 큼직한 것을 고릅니다. 사진이 예쁜 것보다 **글자 자리가 단순한 것**이 낫습니다.

### 2단계 — 문구 교체

템플릿 글자를 두 번 눌러 AI가 준 문구로 바꿉니다. 1장부터 5장까지 순서대로. 글자가 넘치면 Canva에서 줄이지 말고 AI에게 "3장 본문을 절반으로" 요청하세요.

### 3단계 — 사진 교체

템플릿 사진 자리에 우리 가게 사진을 올립니다. 사진이 없으면 [AI 이미지 페이지](../04-ai-image)에서 만든 이미지를 씁니다.

### 4단계 — 다운로드

오른쪽 위 공유 → 다운로드 → PNG. 5장이 한꺼번에 내려옵니다. 인스타에서 여러 장 선택해 올리면 끝.

{{% /steps %}}

색상·폰트는 템플릿 그대로 두세요. 바꾸기 시작하면 30분 갑니다.

## 이건 나중에: 두 번째 카드뉴스 주제 예시

첫 카드뉴스를 올린 뒤에 시도하세요. 프롬프트는 위와 같고 **주제·목적·4장 근거**만 바꿉니다.

### 업종 예시 완성본 (학원 "성장영어")

```text
[컨텍스트 카드: 초등 영어학원 "성장영어", 학부모 대상, 정중한 존댓말, 소수 정예 6명 반]

인스타그램 카드뉴스 5장 문구를 써 줘.
주제: 우리 학원이 다른 이유 5가지
목적: 겨울방학 신규 상담 문의 받기

구조:
1장 표지 — 제목 12자 이내, 부제 20자 이내
2장 문제 — 학부모가 겪는 고민 2문장
3장 해결 — 우리 학원의 5가지 차별점을 한 줄씩 (실제 사실만: 6명 정원, 매주 학부모 피드백 문자, 원어민 주 1회, 레벨 테스트 무료, 셔틀 운행)
4장 증거 — 아래 실제 학부모 후기 근거로 1–2문장. 없는 사실 지어내지 말 것
   후기: "매주 피드백 문자 와서 아이가 뭘 배우는지 알 수 있어요"
5장 행동 — 뭘 하면 되는지 1문장 + "전화 또는 인스타 DM으로 상담 예약"

각 장은 "N장 / 제목 / 본문" 형식으로. 카드 안에 들어갈 글이니 짧게.
마지막에 게시글 캡션 3줄과 해시태그 10개도 따로.
```

### 예상 결과

3장이 "5가지"라 길어지므로 AI가 3장을 두 장으로 나누자고 제안하거나, 한 줄씩 5개로 압축합니다. 둘 다 괜찮습니다.

### 다듬는 법

- "학원 광고 같은 말('명문대', '1등') 빼고 학부모가 신뢰할 만한 담백한 톤으로."
- "2장 고민을 학부모 입에서 나올 법한 말로 바꿔 줘. 따옴표 넣어서."

{{< callout type="error" >}}
학원·교육 광고는 "성적 보장", "합격률" 같은 표현에 법적 제약이 있을 수 있습니다. AI가 써 준 문구 중 성과를 단정하는 표현은 빼세요. 확실하지 않으면 관할 교육청 광고 기준을 확인하세요.
{{< /callout >}}

## 흔한 실수

1. **한 장에 글이 너무 많음.** 카드 한 장은 3초 안에 읽혀야 합니다. 넘치면 AI에게 "절반으로" 요청. Canva에서 글자 크기 줄이는 건 최악입니다.
2. **5장 전부 우리 자랑.** 2장 "문제"가 손님 이야기여야 넘겨 봅니다. 손님 고민 없이 시작하면 1장에서 끝납니다.
3. **템플릿 색·폰트 바꾸다가 30분 소모.** 첫 카드뉴스는 템플릿 그대로. 잘 되면 그때 손보세요.

{{< callout type="warning" >}}
**무시해도 되는 것**

- Canva 유료 기능(프리미엄 템플릿, 배경 제거 등). 무료 템플릿으로 이 페이지 전부 가능합니다.
- 포토샵, 미리캔버스 vs Canva 비교. 아무거나 하나 골라 익숙해지면 됩니다. 이 사이트는 Canva 기준입니다.
- "카드뉴스 디자인 트렌드" 검색. 글자 크고 사진 한 장이면 됩니다.
{{< /callout >}}
