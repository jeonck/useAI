⏱ 소요 시간: 8분

✅ **이 페이지를 끝내면 할 수 있는 것**
- "신규 손님" 또는 "재방문"이라고 목표만 말하면 이벤트 3안을 예산·기간·안내문구·SNS 문구까지 한 세트로 받습니다.
- 단골 관리 문자 3종(첫 방문 감사 / 한 달 후 / 생일)을 만들어 저장해 둡니다.
- 경쟁 매장 리뷰를 붙여 넣고 우리 강점을 찾아 홍보 문구에 씁니다.

## 무엇부터: 목표 하나 → 이벤트 3안 세트

이벤트는 "뭘 할까"보다 "누굴 데려올까"가 먼저입니다. 목표는 둘 중 하나만 고르세요.

- **신규**: 우리 가게를 모르는 사람이 처음 오게
- **재방문**: 한 번 온 사람이 다시 오게

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

이벤트 3안을 기획해 줘.
목표: [신규 손님 유입 / 재방문 늘리기] 중 하나
쓸 수 있는 예산: 총 [금액] 이내 (할인·증정품·인쇄비 전부 포함)
기간: [예: 2주 / 한 달]
우리 상황: [비수기 시간대, 잘 나가는 메뉴, 손님 특징 등 1–2줄]

각 안마다:
1. 이벤트 이름 (10자 이내)
2. 내용 한 줄
3. 예산 계산 (뭐에 얼마, 합계)
4. 기간·시간대
5. 매장 안내문구 (입간판·카운터용, 30자 이내)
6. SNS 문구 (인스타 캡션 3줄 + 해시태그 5개)
7. 이 안의 약점 한 줄

3안은 서로 방식이 다르게 (예: 할인형 / 증정형 / 참여형).
마지막에 "예산 대비 가장 안전한 안"을 하나 추천하고 이유 한 줄.
```

### 업종 예시 완성본 (동네 카페 "커피한잔")

```text
[컨텍스트 카드: 동네 카페 "커피한잔", 30대 직장인·주부 손님, 친근한 존댓말, 시그니처 흑임자라떼, 오후 3–5시 한가함]

이벤트 3안을 기획해 줘.
목표: 재방문 늘리기
쓸 수 있는 예산: 총 20만 원 이내 (할인·증정품·인쇄비 전부 포함)
기간: 한 달
우리 상황: 오후 3–5시 한가함. 점심 직후 손님이 많고, 소금빵은 오후 3시쯤 다 팔림. 쿠폰 도장판은 써 본 적 없음.

각 안마다:
1. 이벤트 이름 (10자 이내)
2. 내용 한 줄
3. 예산 계산 (뭐에 얼마, 합계)
4. 기간·시간대
5. 매장 안내문구 (입간판·카운터용, 30자 이내)
6. SNS 문구 (인스타 캡션 3줄 + 해시태그 5개)
7. 이 안의 약점 한 줄

3안은 서로 방식이 다르게 (예: 할인형 / 증정형 / 참여형).
마지막에 "예산 대비 가장 안전한 안"을 하나 추천하고 이유 한 줄.
```

### 예상 결과

예를 들면 1안 "오후 3시 라떼 할인"(할인형), 2안 "도장 5개 소금빵 증정"(증정형), 3안 "인스타 사진 올리면 사이즈업"(참여형)처럼 방식이 다른 3안. 각 안에 예산 계산과 문구가 붙고, 마지막에 추천 하나.

**예산 계산은 AI가 추정한 숫자입니다.** 우리 원가·객단가로 직접 다시 계산하세요. 예산 부분만 다시 시키면 됩니다.

### 다듬는 법

- "2안으로 갈게. 예산을 우리 원가 기준으로 다시 계산해 줘. 소금빵 원가 [금액], 하루 평균 [N]잔."
- "2안 안내문구를 A4 포스터용(제목 + 조건 3줄 + 기간)으로 늘려 줘."
- "직원에게 설명할 운영 규칙 5줄로. 예외 상황(쿠폰 분실, 다른 할인과 중복) 포함."
- 카드뉴스로 만들려면 [카드뉴스 페이지](../02-card-news) 프롬프트에 이 이벤트를 주제로 넣으세요.

{{< callout type="error" >}}
경품·추첨 이벤트는 금액과 방식에 따라 법적 기준(경품 한도, 추첨 공정성 표시 등)이 있을 수 있습니다. 또 "무료", "1+1" 표시 방식도 규정이 있습니다. AI 기획안은 초안입니다. 경품 이벤트를 크게 할 때는 관련 규정을 확인하거나 전문가에게 물어보세요.
{{< /callout >}}

## 그다음: 단골 관리 문자 3종

한 번 만들어 두면 계속 씁니다. 첫 방문 감사 / 한 달 후 안부 / 생일, 이 3개면 됩니다.

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

단골 관리 문자 3종을 써 줘. 각각 80자 이내, 존댓말, 이름 자리는 "OOO님"으로.
1. 첫 방문 감사 — 방문 당일 저녁 발송. 다음 방문 유도 한 줄 포함. 할인 언급 없이.
2. 한 달 후 안부 — 한 달간 안 온 손님에게. 부담 없이. [이번 달 소식 한 줄] 포함.
3. 생일 — 생일 당일. [생일 혜택] 포함. 유효 기간 명시.

각 문자 끝에 "수신거부" 안내 자리는 [수신거부 번호]로 남겨 둬.
말투는 광고 같지 않게, 사장님이 직접 보낸 것처럼.
```

### 업종 예시 완성본 (미용실 "가위손헤어")

```text
[컨텍스트 카드: 동네 미용실 "가위손헤어", 40–60대 단골, 정중한 존댓말, 예약 없이 방문 가능]

단골 관리 문자 3종을 써 줘. 각각 80자 이내, 존댓말, 이름 자리는 "OOO님"으로.
1. 첫 방문 감사 — 방문 당일 저녁 발송. 다음 방문 유도 한 줄 포함. 할인 언급 없이.
2. 한 달 후 안부 — 한 달간 안 온 손님에게. 부담 없이. "이번 달부터 두피 케어 시작했어요" 포함.
3. 생일 — 생일 당일. "이달 중 방문 시 트리트먼트 무료" 포함. 유효 기간 명시.

각 문자 끝에 "수신거부" 안내 자리는 [수신거부 번호]로 남겨 둬.
말투는 광고 같지 않게, 사장님이 직접 보낸 것처럼.
```

### 예상 결과

```text
1. OOO님, 오늘 가위손헤어 찾아 주셔서 감사합니다. 스타일 유지 어려우시면 언제든 들러 주세요. 무료수신거부 [번호]
2. OOO님, 잘 지내시죠? 이번 달부터 두피 케어를 시작했어요. 지나시는 길에 편히 들르세요. 무료수신거부 [번호]
3. ...
```

### 다듬는 법

- "1번이 좀 딱딱해. 동네 미용실 느낌으로 부드럽게."
- "3번에 예약 방법(전화)을 넣어 줘."
- 글자 수가 넘으면: "각 문자 70자 이내로 다시."

{{< callout type="error" >}}
**개인정보 주의.** 손님 이름·전화번호·생일 목록을 AI에 붙여 넣지 마세요. 문자 틀만 AI로 만들고, 이름은 문자 발송 프로그램에서 넣으세요. 광고성 문자는 수신 동의를 받은 손님에게만, "(광고)" 표시와 수신거부 안내가 필요합니다. 규정은 관련 법령 또는 전문가 확인.
{{< /callout >}}

## 이건 나중에: 경쟁 매장 리뷰로 우리 강점 찾기

이벤트 문구에 "우리만의 것"을 넣고 싶을 때. 근처 비슷한 가게 리뷰 20–30개를 복사해 붙여 넣습니다.

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

아래는 근처 [업종] 리뷰야 (가게 이름은 지움). 분석해 줘.
1. 손님들이 반복해서 칭찬하는 것 3가지
2. 손님들이 반복해서 불만인 것 3가지
3. 위 불만 중 우리 가게가 이미 잘하고 있는 것 → 우리 강점 후보
4. 그 강점을 살린 홍보 한 줄 문구 3개 (15자 이내)
5. 우리도 조심해야 할 것 1가지

리뷰:
[리뷰 붙여넣기 — 가게 이름·작성자 이름은 지우고]
```

### 업종 예시 완성본 (헬스장 "튼튼짐")

```text
[컨텍스트 카드: 헬스장 "튼튼짐", 역삼동, 직장인 회원, PT·GX 운영, 힘 있는 존댓말, 밤 11시까지 운영, 샤워실 매일 청소]

아래는 근처 헬스장 리뷰야 (가게 이름은 지움). 분석해 줘.
1. 손님들이 반복해서 칭찬하는 것 3가지
2. 손님들이 반복해서 불만인 것 3가지
3. 위 불만 중 우리 가게가 이미 잘하고 있는 것 → 우리 강점 후보
4. 그 강점을 살린 홍보 한 줄 문구 3개 (15자 이내)
5. 우리도 조심해야 할 것 1가지

리뷰:
- 기구는 많은데 저녁 7시엔 자리가 없어요
- 샤워실 청소가 좀...
- 트레이너분들 친절해요
- 10시에 문 닫아서 야근하면 못 감
- 가격 대비 괜찮음
(… 20–30개)
```

### 예상 결과

불만에 "늦게 닫음", "샤워실 위생"이 반복되면 → 우리 강점 후보 "밤 11시까지", "샤워실 매일 청소" → 한 줄 문구 "야근 끝나도 열려 있어요" 같은 것이 나옵니다. 이걸 [매장 문구 페이지](../03-store-copy)의 입간판 카피나 이벤트 문구에 넣습니다.

### 다듬는 법

- "3번 강점 후보 중 '밤 11시'로 가자. 이걸 살린 신규 회원 이벤트 1안만 위 형식으로."
- "우리 가게 리뷰도 붙일게. 경쟁 매장과 비교해서 우리가 부족한 것 2가지."

{{< callout type="error" >}}
리뷰를 붙여 넣기 전에 작성자 이름·아이디, 가게 상호는 지우세요. 경쟁 매장을 홍보 문구에서 직접 언급하거나 비교하는 표현("OO보다 싸요")은 쓰지 마세요.
{{< /callout >}}

## 흔한 실수

1. **목표 없이 "이벤트 아이디어 줘".** 신규인지 재방문인지 안 정하면 아무 데나 붙는 뻔한 아이디어가 옵니다.
2. **AI가 계산한 예산을 그대로 믿기.** 원가·객단가는 우리만 압니다. 안을 고른 뒤 예산만 다시 계산시키세요.
3. **문자 3종을 손님 목록과 함께 붙여 넣기.** 이름·번호는 절대 AI에 넣지 않습니다. 틀만 만들고 이름은 발송 프로그램에서.

{{< callout type="warning" >}}
**무시해도 되는 것**

- 마케팅 퍼널, 고객생애가치 같은 용어. "신규냐 재방문이냐"만 정하면 됩니다.
- 이벤트 효과 측정 대시보드. 이벤트 전후 2주 매출과 방문 수를 메모앱에 적어 비교하면 충분합니다.
- 경쟁사 분석 보고서 양식. 리뷰 붙여 넣고 위 5가지 질문이면 끝입니다.
{{< /callout >}}
