⏱ 소요 시간: 12분

✅ **이 페이지를 끝내면 할 수 있는 것**
- 메뉴판 설명 문구, 현수막·입간판 한 줄 카피를 글자 수 맞춰 받습니다.
- 네이버 플레이스 소개글과 스마트스토어 상품 상세 설명(장점 3 + FAQ 5)을 직접 씁니다.
- 매장 슬로건 후보 10개 중 하나를 골라 명함·간판·인스타 프로필에 씁니다.

{{< callout type="info" >}}
이 페이지의 핵심 요령 하나: **글자 수 제한을 반드시 줍니다.** "한 줄 카피 써 줘"라고 하면 30자짜리가 옵니다. "12자 이내"라고 하면 현수막에 들어갑니다.
{{< /callout >}}

## 무엇부터: 메뉴판 설명 문구

메뉴 이름 옆에 붙는 한 줄. 이게 있으면 손님이 "이게 뭐예요?"를 덜 묻습니다.

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

메뉴판에 넣을 메뉴 설명 문구를 써 줘. 메뉴당 한 줄, 25자 이내.
재료·맛·추천 상황 중 하나만 골라서. 과장("최고", "환상적") 금지.
메뉴 목록:
[메뉴 이름 — 재료/특징 한 줄]
[메뉴 이름 — 재료/특징 한 줄]
...
표로: 메뉴 | 설명 문구 | 글자 수
```

### 업종 예시 완성본 (동네 카페 "커피한잔")

```text
[컨텍스트 카드: 동네 카페 "커피한잔", 30대 직장인·주부 손님, 친근한 존댓말]

메뉴판에 넣을 메뉴 설명 문구를 써 줘. 메뉴당 한 줄, 25자 이내.
재료·맛·추천 상황 중 하나만 골라서. 과장("최고", "환상적") 금지.
메뉴 목록:
흑임자라떼 — 국산 흑임자 직접 갈아서, 단맛 약함
밤라떼 — 가을 한정, 밤 페이스트, 따뜻하게만
소금빵 — 매일 아침 구움, 오후 3시쯤 소진
애플 시나몬 티 — 카페인 없음, 저녁에 추천
표로: 메뉴 | 설명 문구 | 글자 수
```

### 예상 결과

| 메뉴 | 설명 문구 | 글자 수 |
|---|---|---|
| 흑임자라떼 | 직접 간 국산 흑임자, 달지 않아요 | 17 |
| 밤라떼 | 가을에만, 따뜻하게만 | 11 |
| ... | ... | ... |

### 다듬는 법

- "글자 수 세는 게 틀렸어. 다시 세 줘." (AI가 글자 수를 종종 틀립니다. 최종은 사장님이 직접 세세요.)
- "소금빵 설명은 '오후 3시 전에 오세요' 느낌으로 바꿔 줘."
- 영문 메뉴판이 필요하면: "같은 표에 영어 설명 열 추가. 외국인 손님이 이해할 정도로 쉽게."

## 그다음: 포스터·현수막·입간판 한 줄 카피

글자 수 제한이 전부입니다. 현수막은 멀리서 3초 안에 읽혀야 하니 10–12자, 입간판은 15자, 매장 안 포스터는 20자까지.

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

[용도: 현수막 / 입간판 / 매장 포스터]에 넣을 한 줄 카피 10개 써 줘.
내용: [알릴 것]
조건:
- [N]자 이내 (띄어쓰기 포함). 각 줄 끝에 글자 수 표시.
- 멀리서 3초 안에 읽히게. 어려운 단어 금지.
- 5개는 사실 위주(가격·기간·메뉴), 5개는 한마디 거는 말투.
```

### 업종 예시 완성본 (미용실 "가위손헤어")

```text
[컨텍스트 카드: 동네 미용실 "가위손헤어", 40–60대 단골 많음, 정중한 존댓말, 예약 없이 방문 가능]

입간판에 넣을 한 줄 카피 10개 써 줘.
내용: 평일 오전 10–12시 커트 할인, 예약 없이 바로 가능
조건:
- 15자 이내 (띄어쓰기 포함). 각 줄 끝에 글자 수 표시.
- 멀리서 3초 안에 읽히게. 어려운 단어 금지.
- 5개는 사실 위주(가격·기간·메뉴), 5개는 한마디 거는 말투.
```

### 예상 결과

```text
1. 평일 오전 커트 할인 (11)
2. 예약 없이 바로 커트 (10)
...
6. 오전에 오시면 더 싸요 (12)
7. 지나가다 들르세요 (9)
...
```

### 다듬는 법

- "7번 느낌으로 5개 더."
- "할인 금액을 넣어서 다시. 금액은 [금액]."
- 현수막 두 줄 구성이면: "위 줄 8자 이내 + 아래 줄 12자 이내, 두 줄 세트로 5개."

{{< callout type="error" >}}
"최저가", "1등", "유일한", "100% 효과" 같은 표현은 표시광고법상 문제가 될 수 있습니다. AI가 써 줘도 빼세요. 헬스·미용·건강식품은 특히 효과 단정 표현을 조심하세요. 확실하지 않으면 전문가 확인.
{{< /callout >}}

## 그다음: 네이버 플레이스 소개글

손님이 검색해서 가장 먼저 보는 글입니다. 검색될 만한 단어(동네 이름 + 업종 + 대표 메뉴)가 들어가야 합니다.

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

네이버 플레이스 "업체 소개" 글을 써 줘.
조건:
- 첫 문장에 [동네 이름] + [업종] + [대표 메뉴/서비스]가 자연스럽게 들어가게.
- 5–7문장. 존댓말. 광고 느낌 빼고 사장님이 직접 쓴 것처럼.
- 포함할 사실: [영업시간, 주차, 예약 방법, 대표 메뉴 3개, 특징 1개]
- 마지막 문장은 방문 유도 한 줄.
길이 다른 2가지 버전: 짧은 것(3문장), 기본(5–7문장).
```

### 업종 예시 완성본 (동네 식당 "행복밥상")

```text
[컨텍스트 카드: 백반집 "행복밥상", 점심 직장인·저녁 가족, 푸근한 존댓말]

네이버 플레이스 "업체 소개" 글을 써 줘.
조건:
- 첫 문장에 "역삼동" + "백반집" + "제철 반찬 한상"이 자연스럽게 들어가게.
- 5–7문장. 존댓말. 광고 느낌 빼고 사장님이 직접 쓴 것처럼.
- 포함할 사실: 영업시간 11:00–21:00(일요일 휴무), 건물 뒤 주차 3대, 단체 예약 전화, 대표 메뉴 제육볶음·고등어구이·된장찌개, 반찬 매일 바뀜
- 마지막 문장은 방문 유도 한 줄.
길이 다른 2가지 버전: 짧은 것(3문장), 기본(5–7문장).
```

### 예상 결과

"역삼동에서 제철 반찬 한상을 내는 백반집 행복밥상입니다."로 시작하는 두 가지 길이의 글. 기본 버전을 플레이스에, 짧은 버전을 인스타 프로필에 씁니다.

### 다듬는 법

- "너무 정돈됐어. 사장님이 툭 쓴 느낌으로 문장 하나는 짧게."
- "'매일 바뀌는 반찬'을 첫 문장으로 올려 줘."

## 그다음: 스마트스토어 상품 상세 설명

온라인 판매 사장님용입니다. 상세페이지는 **장점 3개 + FAQ 5개**가 뼈대입니다. 이걸 받아서 사진 사이사이에 넣으면 상세페이지가 됩니다.

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

스마트스토어 상품 상세 설명을 써 줘.
상품: [상품 이름]
사실 정보: [용량/크기, 재료/소재, 원산지, 배송, 가격대, 만드는 방법 등 확실한 것만]
주 구매층: [누가 사는지]

구성:
1. 한 줄 요약 (20자 이내)
2. 장점 3개 — 각각 소제목(10자 이내) + 설명 2문장. 사실 정보에 없는 장점은 만들지 말 것.
3. 이런 분께 추천 — 3줄
4. FAQ 5개 — 손님이 실제로 물어볼 것. 배송·보관·교환·크기·사용법 중에서. 답은 2문장 이내.
5. 주의사항 — 사실 정보 기준으로 2–3줄
```

### 업종 예시 완성본 (온라인 쇼핑몰 "행복문구")

```text
[컨텍스트 카드: 스마트스토어 "행복문구", 손글씨 다이어리·스티커 판매, 20–30대 여성, 밝은 존댓말]

스마트스토어 상품 상세 설명을 써 줘.
상품: 2027 위클리 다이어리 (A5)
사실 정보: A5 크기, 160쪽, 100g 미색 종이, 국내 인쇄, 날짜형(1월 시작), 스프링 제본, 스티커 2장 포함, 주문 후 1–2일 내 출고, 택배 배송
주 구매층: 20–30대 직장인·대학생, 손글씨 기록 좋아하는 분

구성:
1. 한 줄 요약 (20자 이내)
2. 장점 3개 — 각각 소제목(10자 이내) + 설명 2문장. 사실 정보에 없는 장점은 만들지 말 것.
3. 이런 분께 추천 — 3줄
4. FAQ 5개 — 손님이 실제로 물어볼 것. 배송·보관·교환·크기·사용법 중에서. 답은 2문장 이내.
5. 주의사항 — 사실 정보 기준으로 2–3줄
```

### 예상 결과

한 줄 요약 → 장점 3개("펜이 안 비치는 100g 종이" 등) → 추천 대상 → FAQ 5개("스프링이 손에 걸리지 않나요?" 등) → 주의사항. 이 순서 그대로 상세페이지 글 블록에 넣습니다.

### 다듬는 법

- "FAQ에 '교환·반품' 항목이 없어. 추가하고, 답은 [우리 스토어 교환 규정]으로."
- "장점 2번을 사진 캡션처럼 한 줄로 줄여 줘. 사진 밑에 넣을 거야."
- 종이 종류처럼 사실 정보를 잘못 부풀리면: "'수입지'라고 쓴 건 틀렸어. 국내 인쇄, 종이 종류는 모르니 '100g 미색 종이'로만."

{{< callout type="error" >}}
식품·화장품·건강 관련 상품은 "효능", "치료", "다이어트 효과" 같은 표현이 법에 걸릴 수 있습니다. AI가 써 준 문구는 초안입니다. 원산지·성분·인증 표기는 실제 서류와 대조하고, 확실하지 않으면 전문가 확인.
{{< /callout >}}

## 이건 나중에: 매장 슬로건 10개 후보

급하지 않습니다. 명함이나 간판을 새로 만들 때 하세요.

### 복붙 프롬프트

```text
[컨텍스트 카드 붙여넣기]

우리 가게 슬로건 후보 10개 써 줘.
조건:
- 12자 이내. 각 줄 끝에 글자 수.
- 우리 가게만의 사실([특징 1–2개])이 느껴지게. 아무 가게나 붙일 수 있는 말("최고의 맛") 금지.
- 5개는 손님에게 말 거는 투, 5개는 우리 다짐 투.
- 각 슬로건 옆에 어디에 쓰면 좋을지(간판/명함/인스타 프로필/포장) 한 단어.
```

### 업종 예시 완성본 (네일샵 "미소네일")

```text
[컨텍스트 카드: 네일샵 "미소네일", 20–30대 여성, 밝은 존댓말, 예약제, 1인 운영]

우리 가게 슬로건 후보 10개 써 줘.
조건:
- 12자 이내. 각 줄 끝에 글자 수.
- 우리 가게만의 사실(1인 운영이라 한 분씩만 집중, 손톱 건강 우선으로 젤 제거 꼼꼼히)이 느껴지게. 아무 가게나 붙일 수 있는 말("최고의 맛") 금지.
- 5개는 손님에게 말 거는 투, 5개는 우리 다짐 투.
- 각 슬로건 옆에 어디에 쓰면 좋을지(간판/명함/인스타 프로필/포장) 한 단어.
```

### 예상 결과

"한 번에 한 분만 (7) — 명함" 같은 형식으로 10개. 마음에 드는 2–3개를 가족·단골에게 물어보고 고르세요.

### 다듬는 법

- "3번, 7번 느낌으로 5개 더."
- "영어 한 단어 버전도 3개."

## 흔한 실수

1. **글자 수 제한 없이 요청.** 현수막에 안 들어가는 25자 카피가 옵니다. 용도별로 자 수를 정하고, 결과의 글자 수는 직접 다시 세세요.
2. **사실 정보를 안 주고 상세 설명 요청.** AI가 원산지·소재·효과를 지어냅니다. 확실한 사실만 목록으로 주고, "없는 건 만들지 말 것"을 꼭 넣으세요.
3. **10개 후보 중 첫 번째를 고르기.** 첫 번째가 제일 무난하고 제일 밋밋합니다. 끝까지 읽고, "N번 느낌으로 5개 더"를 한 번은 하세요.

{{< callout type="warning" >}}
**무시해도 되는 것**

- 카피라이팅 이론, "후킹 문장 공식" 같은 것. 글자 수 제한 + 사실 정보 + 과장 금지, 이 세 가지면 됩니다.
- 네이버 플레이스 상위 노출 비법. 소개글에 동네·업종·대표 메뉴가 들어가고, 리뷰 답글을 꾸준히 다는 게 먼저입니다(2교시 리뷰 답글 참고).
- 상세페이지 전문 제작 대행 비교. 장점 3 + FAQ 5 + 사진이면 첫 상세페이지로 충분합니다.
{{< /callout >}}
